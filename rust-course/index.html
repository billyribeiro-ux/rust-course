Set up once with mise

Read locally

Check the launch guide for mise, Python 3.11+, Git and native development-tool prerequisites. From the portable course folder, inspect mise.toml before trusting its version selection, environment and local tasks:

mise trust
mise install
mise exec -- rustc --version
mise run course

Open localhost:8000. Python 3 serves static files only. You can also open index.html directly; search uses a local script, not a network fetch.

Build deliberately

Reference implementations and learner scaffolds are separate. From the course root, copy a scaffold with python3 scripts/start-project.py p01; existing learner work is never overwritten. Follow the project workbench to test that learner copy. Lesson reference commands specify projects/ as their Cargo working directory.

Choose your starting point

This diagnostic checks a few prerequisites. A correct guess is not enough: explain it aloud and complete the practical task for any stage you skip.

1. You run a command in the wrong folder. What should you inspect first?

Use pwd and list files. Installation changes do not correct a path. Practical task: create a folder, move into it, and explain a relative path.

2. What is the value of the expression 2 + 3 * 4?

Multiplication has higher precedence, so 3 * 4 is evaluated before adding 2. Practical task: write a function and test its boundary input.

3. After let b = a for a String, which binding owns the value?

The String moves. It is not a Copy type; cloning requires an explicit allocation/copy choice. Demonstrate a borrow that avoids needing a clone.

4. A passing unit test establishes…

Tests support specific claims. They can miss relevant inputs, system boundaries and flawed assertions. Write a counterexample to an overly broad claim.

5. A server completed an operation but its response was lost. Retrying may…

The client has an uncertain outcome. Stable operation identity and deduplication can help, but external effects require explicit reasoning. Draw the failure timeline.
