How idiomatic Rust is assessed

The Rust API Guidelines, matching standard-library contracts, the Edition Guide and the Reference govern the review. The source uses borrowed slices for views, private validated domain values, standard conversion traits, Result with meaningful errors, explicit resource ownership, bounded concurrent work, and small documented unsafe boundaries. Formatting, strict Clippy, doctests, deliberate compiler errors and behavioral tests provide separate evidence. A lint pass alone cannot certify an API or prove unsafe code sound.
