First-project evidence

The calculator uses checked integer arithmetic, rejects non-finite floating input and results, separates parsing from pure operations, handles CLI errors explicitly and propagates doctest failures through Result. Native-path handling avoids implicit non-Unicode argument panics. It uses the standard library because its scope does not need an async runtime, service layer or parsing framework. See the calculator lesson and the affected tests.
