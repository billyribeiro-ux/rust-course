Sixteen projects, one connected path

Reference code is complete only to its documented contract. Scaffolds intentionally leave work for you. Make a learner copy before editing; the helper refuses existing destinations. Start both blocks below in the course root, the folder containing index.html, mise.toml and scripts.

Copy and test your learner project

python3 scripts/start-project.py p01
mise exec -- cargo test --manifest-path learner-work/p01-calculator/Cargo.toml

Open the new copy's README.html and edit its source. The first calculator scaffold deliberately has four failing acceptance tests until you implement its contract. A passing reference test does not establish that your copy works.

Check the supplied references

mise exec -- cargo test --manifest-path projects/Cargo.toml --workspace --locked

The native reference workspace shares one Cargo.lock. UI builds use a separate WASM target and lockfile. A default target/ is rebuildable cache, never part of the portable course archive.
