These are immutable source milestones, not task lists or a hidden final implementation. Materialize each into a new working directory. Existing learner work is never overwritten. Build output is shared through your Cargo target directory and is not copied with a checkpoint.

Reconstruct and verify

Working directory: the course root containing index.html. Python3.11 or newer is needed for the standard-library TOML parser.

python3 scripts/start-checkpoint.py p15 01-append-transport
mise exec -- cargo test --locked --manifest-path learner-work/checkpoints/p15-replication/01-append-transport/Cargo.toml

The helper resolves inherited Cargo fields, copies local path dependencies where needed, and starts from the shared lockfile. Use --destination PATH for another fresh directory. Never reuse a modified working directory as a reconstruction destination.

Milestone contract

A fixed leader proposes up to8 values and produces at most16 pending packets for two followers. A caller can take, delay, drop, or deliver packets. Duplicate delivery is idempotent; gaps, conflicts, and invalid follower indices fail. No acknowledgments, committed prefix, elections, process persistence, or consensus guarantee exists here.

Engineering decisions

Packets are assumed to come from the fixed trusted leader; this model explores delivery faults, not malicious packet forgery. Packet order is explicit data, which makes an experiment reproducible without sleeps or threads. Followers accept only the next index or an exact duplicate. Queue and log admission are checked before proposal mutates state. Delivering a later packet before its prefix must preserve the old follower log. The final lab adds acknowledgment bookkeeping, contiguous commitment and restart actions. That evolution changes the property under test; it does not turn the lab into Raft.

How to use the sequence

  1. Reconstruct00-scaffold for the smallest runnable premise. Predict its tests and explain its explicit scope.
  2. Reconstruct01-append-transport separately. Read its complete src/lib.rs, run tests, and make one change that exercises its contract.
  3. Reconstruct final in a third directory. Compare source and tests; identify each new resource, state transition, and failure boundary.

For any selected ID, replace the second argument of the reconstruction command. The final snapshot references immutable reference source rather than duplicating a second large tree. The manifest records all IDs and sources. The corresponding lesson is 08-replication.

Practice and evidence

Do not infer later features from a passing early test. Before reading final, write the next milestone's acceptance criteria and name a plausible implementation defect that the current tests would miss. Then identify the reference test that addresses it, or add your own experiment in the learner copy. Record command, expected result, observed result, and remaining uncertainty.
