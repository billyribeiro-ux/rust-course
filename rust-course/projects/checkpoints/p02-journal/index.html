Engineering decisions at this checkpoint

A private Vec fits a maximum of 32 tasks and makes insertion order explicit. Borrowed input becomes one intentional owned title only after validation, and readers receive a slice. A BTreeMap is a reasonable alternative if keyed lookup becomes the main operation; it would change the presentation-order decision. Tests verify retained title ownership, idempotent completion, rejected-state preservation and the exact capacity boundary. Persistence requires a separate encoding and file protocol; this milestone makes no durability claim.
