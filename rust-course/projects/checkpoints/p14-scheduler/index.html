These are immutable source milestones, not task lists or a hidden final implementation. Materialize each into a new working directory. Existing learner work is never overwritten. Build output is shared through your Cargo target directory and is not copied with a checkpoint.

Reconstruct and verify

Working directory: the course root containing index.html. Python3.11 or newer is needed for the standard-library TOML parser.

python3 scripts/start-checkpoint.py p14 01-lease-model
mise exec -- cargo test --locked --manifest-path learner-work/checkpoints/p14-scheduler/01-lease-model/Cargo.toml

The helper resolves inherited Cargo fields, copies local path dependencies where needed, and starts from the shared lockfile. Use --destination PATH for another fresh directory. Never reuse a modified working directory as a reconstruction destination.

Milestone contract

An in-memory queue retains at most16 jobs,256-byte payloads, three claims per job, and ten logical ticks per lease. Exact enqueue retries have no new effect; conflicting payloads fail. Expiry permits redelivery and a newer token fences old completion. Cancellation revokes completion. No database, OS clock, background worker, or external effect is implemented.

Engineering decisions

Logical time is a caller-supplied nondecreasing tick counter; it is a simulation input, not a wall-clock guarantee. Expiry at now equal to the deadline is explicit. Completion inserts a database-like effect into an in-memory set and then marks done within one synchronous method. That method is atomic only with respect to this single-threaded model; the final SQL transaction is required for durable concurrent authority. Reaching the attempt limit intentionally transitions to Failed while returning an explanatory error. Overflow rejects before claiming. A smaller enum transition model is checkpoint00; a persistent concurrent claim using SQL locks is the final checkpoint.

How to use the sequence

  1. Reconstruct00-scaffold for the smallest runnable premise. Predict its tests and explain its explicit scope.
  2. Reconstruct01-lease-model separately. Read its complete src/lib.rs, run tests, and make one change that exercises its contract.
  3. Reconstruct final in a third directory. Compare source and tests; identify each new resource, state transition, and failure boundary.

For any selected ID, replace the second argument of the reconstruction command. The final snapshot references immutable reference source rather than duplicating a second large tree. The manifest records all IDs and sources. The corresponding lesson is 08-delivery.

Practice and evidence

Then identify the reference test that addresses it, or add your own experiment in the learner copy. Record command, expected result, observed result, and remaining uncertainty.
