Engineering decisions at this checkpoint

This bounded in-memory framing model validates a full record before publishing its payload or advancing the valid-prefix boundary. The byte-sum checksum deliberately permits undetected compensating changes: it is a framing exercise, not a temporary durable-store integrity mechanism endorsed until later. The KV01 reference is a different explicitly specified format with CRC32 and semantic records. Tests distinguish complete detected damage from incomplete suffixes and exercise the input budget. File ownership, syncing, locking and crash assumptions require their own later protocol; none is implied by this parser.
