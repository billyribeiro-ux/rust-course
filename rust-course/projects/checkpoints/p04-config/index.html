Engineering decisions at this checkpoint

Private validated Config storage prevents safe callers from assigning port zero. The implementation borrows candidate text, traverses at most eight layers, and validates the final selected value. iter().flatten() visits only present layers; overwriting the local selected reference makes later layers win without altering caller data. A named Layer type is appropriate when several settings join the contract; this single-setting milestone does not need a map. Boundary tests cover defaulting, overridden malformed input, final rejection and layer capacity.
