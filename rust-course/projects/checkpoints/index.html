Small source snapshots · shared build cache

Reconstruct a runnable checkpoint

Scaffolds are independent assignments and may contain explicitly labeled unfinished work. These checkpoints are complete to the contract shown below. The helper creates a new learner directory and refuses to overwrite existing work. Earlier milestones have smaller requirements; final checkpoints use the immutable reference source and materialize their Cargo manifests and local helper dependencies.

python3 scripts/start-checkpoint.py p01 01-checked-add
# The helper prints the new directory and its exact commands.

Run the helper from the course folder. Read each checkpoint’s supported inputs and engineering decisions before expanding it. All native learner builds inherit the course’s mise target directory unless you intentionally select another shared cache. UI builds use scripts/build-ui.py --project with a separate WASM cache. Generated build output never belongs in a source checkpoint.

Machine-readable checkpoint manifest

01-checked-add · Checked scalar addition before units

Parse two bounded signed decimal i64 strings and return their checked sum. Invalid numbers and arithmetic overflow are different errors. This stage deliberately has no units, operator selection, or general CLI parser. The executable propagates output-write/flush failures instead of panicking; arithmetic errors remain distinct in the library.

Expiry permits redelivery and a newer token fences old completion. Cancellation revokes completion. No database, OS clock, background worker, or external effect is implemented.
