Core Rust laboratories

Three focused, dependency-free supplements support the sixteen-project path. They teach collections, validated conversion traits and iterator pipelines, and controlled single-threaded interior mutability. Each has a complete reference, named behavior tests, an executable example, an independent extension, and a source reconstruction helper.

  • Collections lesson: bounded label counts, deterministic output, tuples, arrays, vectors and borrowed slices.
  • Conversions lesson: Percent constructors, standard traits, closure capture and preserving batch errors.
  • Interior-mutability lesson: Rc ownership, Cell flag, fallible RefCell access, reentrancy, weak observers and RAII cleanup.

Run the reference

From the course projects directory:

mise exec -- cargo test -p core-rust-labs
mise exec -- cargo run -p core-rust-labs --example collections
mise exec -- cargo run -p core-rust-labs --example conversions
mise exec -- cargo run -p core-rust-labs --example interior

Reconstruct one complete checkpoint

From the course root, choose one lab and a new destination name. The helper refuses existing learner work. The standalone package has only the selected module and example; it needs no inherited workspace dependencies.

python3 projects/reference/p18-core-labs/reconstruct.py collections --name collections-lab
cd learner-work/collections-lab
mise exec -- cargo test
mise exec -- cargo run --example collections

Substitute conversions or interior consistently to build the other checkpoint. This copies a complete reference checkpoint for guided inspection. The independent extensions in each lesson still require your own specification, implementation and evidence. Preserve your first generated application lockfile and review changes with Git.

Evidence and limits

Unit tests and executable documentation and example, Clippy, reconstruction and deliberate-mutation checks record actual author verification. No browser claim or independent acceptance is implied. Read engineering decisions and the investigation playbook before extending the scope.
