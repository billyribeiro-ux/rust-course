Engineering decisions and evidence

Requirements and invariants

Retain at most the configured line payload, count each physical line once, drain oversized lines, propagate read/write failures and reject input beyond its total-byte budget. Summary categories partition all counted lines; severity counters partition valid records. Search matches are a subset of valid records. UTF-8 views never outlive the stable current line. Output already written may remain when a later operation fails.

Chosen design and concrete habits

The shared scan state machine uses fill_buf and consume. analyze supplies a discard writer with no query; search supplies a bounded literal and the caller's writer. Fixed counters avoid a service-name map with attacker-controlled cardinality. A parsed Record borrows its fields for immediate accounting, while str::contains searches the whole validated line without byte indexing. write_all handles short writes and returns ordinary failures. The CLI uses args_os for native paths, validates textual options, owns stdout flushing and reports success only after that flush.

Meaningful alternative and evolution threshold

A whole-file buffer is suitable only under a separately justified small-file memory contract. Raising --max-bytes changes the allowed work, not the retained-line bound. Regular expressions, normalized or case-insensitive Unicode matching require explicit semantics and may justify a maintained library. Per-service aggregation needs bounded cardinality. A blocking byte budget does not provide a wall-clock deadline. Atomic output publication would require a separate temporary-file and replacement contract; this tool deliberately exposes streaming prefix-on-error behavior.

Actual checks and remaining uncertainty

The search follow-up records unit, CLI, integration and documentation tests, strict Clippy, all-target checking and formatting. A generated reader processed 67,109,888 bytes from one 1 KiB record through a 257-byte reader, with all 65,537 records counted and matched. Unicode, partial output failures, a read error after emitted output, Interrupted retry and budget boundaries are tested. This supports the declared stream contract; it is not an RSS benchmark or proof for every input. Reader/writer storage and allocator overhead add memory. Independent review remains pending.
