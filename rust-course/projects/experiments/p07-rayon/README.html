Serial, scoped threads and Rayon

This isolated workspace fingerprints an already-read bounded batch through three strategies and rejects unequal ordered outputs. It does no filesystem or network I/O. Maximum input is 128 buffers of 64 KiB each (8 MiB payload); worker counts are 1 through 8.

# From rust-course/projects
mise exec -- cargo test --locked --manifest-path experiments/p07-rayon/Cargo.toml
mise exec -- cargo run --release --locked --manifest-path experiments/p07-rayon/Cargo.toml

The normal fixture has 32 buffers of 32 KiB and uses 4 workers. All strategies share the same immutable input. Rayon 1.12.0 is exact-pinned with a standalone lockfile. Use the course's shared mise target directory. This is a behavior comparison, not a speed benchmark. The final file indexer retains its bounded blocking-I/O workers and streaming memory policy.
