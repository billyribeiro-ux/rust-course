Log Detective learner scaffold

This crate intentionally contains two todo!() functions and six failing acceptance tests. These are learner work, not recommended runtime error handling or a passing reference.

From the course root, make a separate learner copy:

python3 scripts/start-project.py p03
mise exec -- cargo test --manifest-path learner-work/p03-logs/Cargo.toml

The helper refuses an existing destination. Edit that copy. First implement bounded line framing, then the strict record grammar and summary, then literal search. Use the complete framing checkpoint only after making a prediction.

Acceptance contract

analyze preserves all input categories. search adds case-sensitive literal substring matching over whole valid UTF-8 records without changing the summary. Emit matches immediately through the supplied Write, normalize CRLF/final endings to LF, and propagate partial write failures. Invalid and oversized records are never emitted. Enforce positive total-byte budgets, a 1–1,048,576-byte line limit and a 1–4096-byte non-control query. A failure can leave a prefix of output; never claim that prefix is a complete result.

After the library works, add the CLI options --contains and --max-bytes, preserving native file paths and handling expected failures through Result and a nonzero exit. See the reference contract for exact stdout/stderr behavior. Use fixed counters rather than an unbounded service-name map. Add tests for chunk boundaries, IO failures and Unicode before comparing implementations.

Retain the investigation: expected/actual behavior, competing hypotheses, a small disconfirming experiment and the final invariant. Engineering decisions belong beside the code you wrote. Reference tests do not verify your learner copy.
