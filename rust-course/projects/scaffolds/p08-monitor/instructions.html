P08 learner scaffold

This standalone learner package is intentionally unfinished. Its acceptance tests should initially fail at the explicit TODO. Keep your work separate from the runnable reference.

Start with deterministic deadline arithmetic: `mise exec -- cargo test --manifest-path scaffolds/p08-monitor/Cargo.toml` from `rust-course/projects`. Then add Tokio as pinned in the parent reference workspace and implement local-only health requests with bounded status-line parsing. Keep a per-attempt timeout and a total endpoint timeout; backoff consumes the total budget. Use a bounded task set, not one waiting task per endpoint. Join or abort and drain every task on shutdown.

Use listeners bound to `127.0.0.1:0` in tests: success, malformed line, 503 then 200, accepted socket that never responds, shutdown while connected, and rejecting a non-loopback literal. Never probe an internet endpoint for these exercises. Record where cancellation takes effect and what dropping a future cannot undo. The reference's limited HTTP parser is a teaching transport; document unsupported redirects, TLS, body parsing and HTTP framing.
