P07 learner scaffold

This standalone learner package is intentionally unfinished. Its acceptance tests should initially fail at the explicit TODO. Keep your work separate from the runnable reference.

From `rust-course/projects`, run `mise exec -- cargo test --manifest-path scaffolds/p07-indexer/Cargo.toml`. Implement the streaming counter, then put it behind a bounded producer/worker/collector pipeline. Do not read entire files or hold the receiver lock during work. Add configuration and metadata limits, cooperative cancellation, deterministic sorting and per-file errors. The pure-reader tests should remain unchanged when concurrency is introduced.

Acceptance beyond these starter tests: queue capacity one with forty jobs terminates; one bad path does not hide valid results; cancellation closes all workers; output is equal across repeated runs; peak active work never exceeds the configured cap. Explain the memory bound as jobs plus workers plus collected results, and identify that regular-file I/O can block cancellation. Capture one experiment disproving the idea that more workers always improve throughput.
