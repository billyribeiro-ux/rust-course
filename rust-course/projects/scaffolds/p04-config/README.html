typed-config learner scaffold

This crate intentionally contains `todo!()` and failing tests. Do not count it as a passing reference.

From `rust-course/projects`, run `mise exec -- cargo test --manifest-path scaffolds/p04-config/Cargo.toml`. Implement one contract at a time. Compare with `reference/p04-config` only after writing a prediction and a failing example. The reference has additional domain, IO, and boundary tests beyond this starter.

The scaffold contract uses fallible Results from the first checkpoint. `todo!()` marks intentionally unimplemented learner work, not recommended error handling. Do not replace routine failure with unwrap; use the typed errors and explicit invariants demonstrated by the reference. Engineering decisions are in the corresponding HTML lesson.
