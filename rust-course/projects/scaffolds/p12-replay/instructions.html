P12 learner scaffold

This standalone learner package is intentionally unfinished. Its acceptance tests should initially fail at the explicit TODO. Keep your work separate from the runnable reference.

From `rust-course/projects`, run `mise exec -- cargo test --manifest-path scaffolds/p12-replay/Cargo.toml`. Implement exact price parsing first. Build distinct order/event ID types and a bounded ordered map. Every rejected event must leave the whole state and expected sequence unchanged. Choose and document whether IDs may be reused after cancellation; the reference permits reuse once absent. Compare complete states across identical streams before trusting a digest.

Then write a generated streaming workload and a benchmark executable. Measure release builds with a warm-up and multiple samples, keeping generation and digest work consistently inside or outside timing. Retain counts, seed/rule, compiler version, profile, hardware, background load and all samples. Never invent a target throughput. Explain how your evidence separates a parsing improvement from changed validation semantics. This is a synthetic state machine, not a trading model or profitability exercise.

Independent file-ingestion extension

After exact prices and ordered events, specify the five-field synthetic tick schema from the replay lesson. Implement a reader that rejects an overlong line before retaining unbounded bytes, enforces ID/timestamp/symbol/event budgets, and computes exact per-symbol count, volume, notional and first/last/low/high values. Treat the input path as a native path. Define duplicates and failed reads before coding, test against the supplied reference fixture, and compare results across bounded batch sizes. The complete reference lives in the separately revealed tick_replay binary; the scaffold stays intentionally unfinished.
