P13 learner scaffold

This standalone learner package is intentionally unfinished. Its acceptance tests should initially fail at the explicit TODO. Keep your work separate from the runnable reference.

Start under `forbid(unsafe_code)`: `mise exec -- cargo test --manifest-path scaffolds/p13-unsafe/Cargo.toml` from `rust-course/projects`. Specify full/empty behavior and ownership before introducing `MaybeUninit`. When the safe baseline passes, preserve it as an oracle. In a separate module write the fixed-array implementation with private storage and length, invariant comments and one justification per unsafe operation.

Required evidence: zero capacity; bounds; full insertion returns the value; non-Copy drops exactly once; zero-sized values with destructors; over-aligned values; repeated push/pop against the safe model; clear during a single destructor panic. A second panic while unwinding may abort the process. Miri is an optional separately installed nightly toolchain check, managed through mise; it is not part of the stable setup and a pass is not a general soundness proof. Do not change global Rust defaults. A review should explain every precondition even when tests pass.
