Editions, channels and support claims

An edition chooses language compatibility rules for a crate; it is not a compiler version. Crates of different editions can interoperate. Stable is the supported release channel; nightly is needed for experimental tools such as Miri, with its own dated toolchain. rust-version declares a minimum supported compiler (MSRV). This course declares and tests 1.99, and does not claim all dependency feature combinations work on earlier versions simply because individual crates list lower MSRVs.

How idiomatic Rust is assessed

The Rust API Guidelines, matching standard-library contracts, the Edition Guide and the Reference govern the review. The source uses borrowed slices for views, private validated domain values, standard conversion traits, Result with meaningful errors, explicit resource ownership, bounded concurrent work, and small documented unsafe boundaries. Formatting, strict Clippy, doctests, deliberate compiler errors and behavioral tests provide separate evidence. A lint pass alone cannot certify an API or prove unsafe code sound.

See the October 17 audit for exact scope, current results and remaining verification limits. Older logs retain their original dates and versions.
