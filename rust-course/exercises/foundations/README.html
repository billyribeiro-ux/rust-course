Deliberately failing compiler exercises

These files are intentional investigations, not reference build failures. From exercises/foundations/ in the portable course, create a separate diagnostics directory, then use the command listed in expected-errors.json. Rust 1.99.1 should exit nonzero and include the specified primary error code. Compiler wording can change.

Write the violated ownership or type relationship in your own words. Save a corrected copy in your learner directory. Preserve the original fixture so the expected-error check remains useful.

Record the version, diagnostic, hypothesis, smallest experiment, fix and remaining uncertainty using the investigation template. A successful compile checks type relationships in that program. It does not prove arithmetic, persistence or application requirements correct.
