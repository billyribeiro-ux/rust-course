  • Delayed-lock fixture observes PostgreSQL waiting before advancing its injected clock, then proves expired authority produces no effect. Validity is sampled under lock, not promised at physical commit completion.
  • Actual effect constraint failure leaves status running and no effect; after removal the valid lease can complete. Third abandoned attempt becomes dead.
  • HTTP router extracted without new dependencies; nine actual loopback cases test authentication/input/body rejections before database work.
  • Transactional outbox is taught as a pattern and extension; reference effect table is not falsely described as a delivered external relay.
