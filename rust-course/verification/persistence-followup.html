Persistence follow-up: exact boundaries and honest recovery claims

Verified October 9, 2026 with Rust and Cargo 1.99.0 through mise. This is an author-team technical audit; independent review remains pending. The work focused on concrete unexplored failure cases instead of repeating unchanged builds.

Findings and changes

  • p06-kv: reproduced defect fixed

    Retaining a relative data path let a later cwd change redirect compaction and subsequent appends to another file. Store::open now captures std::path::absolute(path)? before lock/data I/O.

  • p06-kv: documented format limitation with executable counterexample

    Changing an originally complete record value length from 3 to 4 yields a bounded declared payload that ends at EOF. Replay reports a torn suffix before CRC validation; open truncates it. Recovery assumes interrupted append with earlier valid bytes unchanged.

  • p06-kv: existing design verified more precisely

    Existing create_new compaction refuses a pre-existing temporary file. Extended assertion confirms its exact original bytes remain unchanged; no cleanup deletes unowned files.

  • p16-workbench: missing boundary evidence added; no production defect found in this audit

    Exactly 16,384 bytes accepted; 16,385 bytes and missing newline rejected without changing bytes. Exactly 10,000 records replay; new command rejected before append; 10,001 records rejected without repair.

  • p16-workbench: documented integrity limit with executable counterexample

    Legal synthetic price alteration 125 to126 retains valid JSON, positions and domain semantics, so replay succeeds with changed cash. Position/schema validation is not corruption detection or authentication.

What the experiments distinguish

The key-value regression changes current directory only inside a child process that runs a single selected test. Its parent owns the temporary directory and cleanup. This protects other parallel tests from process-global cwd changes. The before-fix run failed when reopening the original file; the same behavior now passes after the path is made absolute at opening. No symlink or external directory identity guarantee follows from this result.

The KV01 counterexample changes a length field in an owned disposable file. It documents the existing incomplete-suffix policy rather than changing the format. CRC cannot reject a mismatch before the parser has the declared payload. Preserve original bytes before investigating unknown damage. The workbench comparison demonstrates the opposite policy for detected malformed records: it preserves bytes and rejects startup. However, its lack of a checksum allows valid-looking changes. Neither project authenticates stored history.

The workbench count fixture writes a complete legal prefix in one operation. It checks replay and later admission; it is not a claim that ten thousand individually acknowledged writes survived power loss. The exact byte-limit tests include a missing newline because valid JSON alone is insufficient framing for the JSONL journal.
