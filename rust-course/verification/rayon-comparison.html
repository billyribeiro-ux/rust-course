Serial, scoped threads and Rayon

The isolated experiment passed three tests and strict all-target Clippy. Its release demo processed 32 buffers totaling 1 MiB with a four-worker pool and verified identical ordered fingerprint vectors across all three strategies. Tests cover empty, single, uneven and maximum-count batches at 1, 2, 4 and 8 workers. This is a behavior comparison; no speed ranking is claimed.

Rayon 1.12.0 is exact-pinned, published April 14, 2026 before the requested cutoff. Its official pool documentation supports explicit local thread budgets. The standalone lockfile leaves the reference workspace graph unchanged. The cached advisory scan found no known vulnerabilities or warnings.

The blocking file indexer retains bounded I/O workers. This CPU experiment accepts at most 8 MiB of input payload and does no file reads. Actual thread activity, scheduler overhead, timing and memory beyond payload were not measured. Independent acceptance remains pending.
