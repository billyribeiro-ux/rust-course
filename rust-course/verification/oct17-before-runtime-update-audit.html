Idiomatic Rust: explicit criteria and examples

This review uses the Rust API Guidelines, versioned standard-library contracts and the Edition Guide. Lint success is one signal, separate from API design and behavior.

  • Validated Percent values use TryFrom, From and FromStr with meaningful errors, following the standard conversion contract. Conversion does not hide fallibility.
  • Journal APIs borrow strings and slices for views, keep state private, use checked arithmetic, and preserve I/O error sources through the standard Error trait.
  • The new let-chain example uses edition 2024 conditional bindings and explicitly explains when Result is preferable to collapsing causes into Option. Rust 1.88 stabilized this syntax.
  • The unsafe container has small documented safety boundaries, initialized-prefix invariants and ownership-aware destruction. Native tests, release tests and seven Miri cases provide distinct evidence; they do not prove all possible safe callers sound.
  • The FFI and audit lessons incorporate Rust 1.99 guidance on C variadic definitions and Box ownership transfer. Fixed signatures remain appropriate for the small host example.
  • Temporary test directories now establish ownership with atomic sequence allocation and create_dir before cleanup. Relaxed ordering supplies uniqueness; it is not used to publish unrelated memory.
