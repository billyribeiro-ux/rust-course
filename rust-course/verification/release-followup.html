What the source and tests support

The calculator and expression evaluator use checked integer operations. Floating length conversion rejects nonfinite and zero-underflow results. The expression boundary test now covers addition, subtraction, multiplication, negation, division overflow, exact operator spans and representable extrema. The replay test privately injects sequence and accepted counter maxima, then proves both place and cancellation rejection preserve the entire state. The accepted-counter injection is defensive branch coverage, not a claim that ordinary public API operations reach that inconsistent state.

Replay ordinary products are bounded by validated values: price at most 1012 ticks times quantity at most 109 fits u128. Parser indices and depth increments stay bounded by source/token/depth limits. FixedSlots checks its private length/capacity invariant before increments or decrements. Its optimized tests cover zero capacity, owned values, zero-sized elements, alignment, mutable access and one destructor panic. Hash/PRNG wrapping operations are intentional. The only debug-assertion configuration branches refuse benchmark timing in a debug executable; domain validation does not rely on them.

Limits and packaging handoff

Tests and source review support the listed invariants; they do not prove all executions or unsafe soundness. Prior Miri evidence remains a separate check. Default unwinding was tested; abort mode and simultaneous destructor panics were not. Metadata resolution is not a fresh build of every reconstructed project. No browser was used. The archive snapshot predates these two new test bodies and this report, so final packaging must include the later source and evidence. The audit records the exact input archive hash rather than claiming it verified a future package.
