Verification evidence / Author follow-up

Keep uncertain replay requests identifiable

A request timeout can occur after a durable write. The previous replay button created a fresh job ID on every click. Its error message told the learner to inspect jobs, but the page did not retain a retryable request. This made it easy to turn a retry into a different logical operation.

The corrected ReplaySubmission keeps both ID and ticks. A refreshed quote does not alter an uncertain retry. A subsequent 422 or429 response cannot prove the first request failed; the draft stays retained until success or a definite rejection of the first attempt. The button shows “Retry retained replay,” with the retained ID and a keep-open notice. There are no automatic mutation retries.

Evidence and limits

Seven native UI-model tests passed. The two new tests exercise timeout, conflict, validation/overload rejection, new quote sequences, exhausted sequences, eventual acceptance and definite first rejection. One test intentionally supplies an ID generator that panics if called on retry: reaching it would expose creation of a second operation. Strict native and WASM Clippy checks and the complete wasm-bindgen build passed. Exact commands/output · Check records.

This is state-decision and compiler evidence. Browser rendering, event handling, request delivery and focus remain unverified because the saved localhost permission blocks Browser Use. The retained draft lives only in the open page. Production persistence of uncertain client commands requires additional storage, expiry and reconciliation design.

Keep verification artifacts in the selected cache

A global Cargo configuration now sets a separate intermediate build directory. The official Rust1.99 Cargo documentation distinguishes build.build-dir from final build.target-dir. A helper accepting a cache path must account for both. The verification and UI build helpers now pass a command-local CARGO_BUILD_BUILD_DIR matching their selected target directory. Global configuration and debug/incremental behavior are preserved. This is path control, not reclaimed space.

Cargo1.99 primary reference; the installed1.99 documentation was read when the web tool could not retrieve the versioned URL. Detailed findings and source hashes.
