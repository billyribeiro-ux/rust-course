Deliberate scope and further work

  • The reader is a review draft. Independent review remains pending, and no learner competence is asserted.
  • Identity tokens are public loopback-only test fixtures. Production authentication, deployment hardening and an identity-provider integration are outside the implemented contract.
  • File persistence guarantees are explicitly bounded: the journal and KV labs do not establish every power-loss/filesystem behavior. The current database fixture passed against PostgreSQL 18.6 on October 17; earlier PostgreSQL 16.15 records retain their original scope.
  • Replication uses a deterministic teaching simulator with a fixed-leader contract, not a claimed Raft implementation or production consensus system.
  • Finite exhaustive properties, a 10,000-input fuzz smoke campaign, fault fixtures and recorded resource profiles are scoped evidence. They do not constitute exhaustive fuzz coverage, formal proofs, every allocator behavior or long-running SLO measurements.
  • The optional Svelte 5 bridge is a separate runnable read-only client with compiler/build and Node tests. Browser layout, refresh, filtering, cancellation and offline recovery have live Chrome evidence. It uses Vite, not SvelteKit. Embedded/FFI examples cover narrow host contracts, not flashed hardware or broad C-library safety.
  • Advanced assessment extensions deliberately ask for designs beyond the runnable baseline and reveal reference approaches separately. They are not silently counted as implemented product features.
