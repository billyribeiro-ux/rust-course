Stream logs with bounded lines and honest accounting

Stream, validate, search and summarize Unicode log records with explicit memory and work budgets.

Read with a terminal open. Predict before revealing. Verified source versions: version ledger.

Prerequisites and learning objectives

  • Separate streaming from bounded buffering
  • Drain oversized records and resume at the next boundary
  • Prove accounting relationships over accepted and rejected lines
  • Perform case-sensitive UTF-8 literal search without retaining matches

Purpose: one bad line must not control memory

A log analyzer may process a large file without needing all of it at once. Streaming means you consume a sequence incrementally. Bounded buffering is the stronger claim that retained data cannot grow beyond an explicit limit. Using BufRead::lines streams across records, but a single line can still be arbitrarily long. A file containing ten million bytes before its first newline defeats the casual claim that “one line at a time” guarantees small memory use.

The CLI limits each line to 4096 bytes before the LF delimiter and defaults to a 64 MiB total-input budget. An explicit --max-bytes N raises that budget for larger files without raising the retained-line limit. Oversized lines are drained and counted separately. Invalid UTF-8 or malformed records are counted as malformed. IO failures and total-input exhaustion return an error rather than a misleading partial report. These are policy decisions: some applications need fail-fast ingestion, others tolerant ingestion with rejection counts. The chosen policy must be visible in both types and output.

The record grammar is intentionally strict: unsigned timestamp, known uppercase level, an ASCII service identifier, then a nonempty message. Single spaces separate the first fields; remaining spaces belong to the message. There is no timezone conversion or free-form date parsing. A timestamp is an integer supplied by the log producer. Decide what a field means before choosing a parser; a sophisticated parser cannot repair an unspecified format.

Guided checkpoint: observe, retain, consume

Read read_bounded as a small state machine. fill_buf exposes available bytes borrowed from the reader. Search that slice for LF. Decide how many bytes belong to this chunk and whether retaining them would exceed the line limit. Copy only while the line remains within the bound. If it becomes oversized, clear the retained data, set the oversized flag, and keep consuming until LF or end-of-input. consume advances the reader after the borrowed buffer has been inspected.

The distinction between retained bytes and consumed bytes is the core of the algorithm. Once a line is oversized, refusing to consume further bytes would revisit the same chunk forever. Returning immediately without draining would interpret the tail of the oversized line as a new record. The flag remembers that the current physical line has already been rejected while the reader moves to the next trustworthy boundary.

//! Bounded-memory, line-oriented log analysis with borrowed record fields.
//! ```
//! use log_detective::{analyze, Limits};
//! let report = analyze(&b"10 INFO api ready\n11 ERROR api unavailable\n"[..], Limits::default())?;
//! assert_eq!(report.errors, 1);
//! assert_eq!(report.valid, 2);
//! # Ok::<(), std::io::Error>(())
//! ```
use std::io::{self, BufRead, Write};
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Level {
    Info,
    Warn,
    Error,
}
#[derive(Debug, PartialEq, Eq)]
pub struct Record<'a> {
    pub timestamp: u64,
    pub level: Level,
    pub service: &'a str,
    pub message: &'a str,
}
pub fn parse_record(input: &str) -> Result<Record<'_>, &'static str> {
    let mut fields = input.splitn(4, ' ');
    let timestamp = fields
        .next()
        .ok_or("timestamp missing")?
        .parse()
        .map_err(|_| "invalid timestamp")?;
    let level = match fields.next() {
        Some("INFO") => Level::Info,
        Some("WARN") => Level::Warn,
        Some("ERROR") => Level::Error,
        _ => return Err("invalid level"),
    };
    let service = fields.next().ok_or("service missing")?;
    if service.is_empty()
        || !service
            .bytes()
            .all(|b| b.is_ascii_alphanumeric() || b == b'-' || b == b'_')
    {
        return Err("invalid service");
    }
    let message = fields.next().ok_or("message missing")?;
    if message.trim().is_empty() || message.chars().any(char::is_control) {
        return Err("invalid message");
    }
    Ok(Record {
        timestamp,
        level,
        service,
        message,
    })
}
#[derive(Clone, Copy, Debug)]
pub struct Limits {
    pub max_line_bytes: usize,
    pub max_total_bytes: u64,
}
impl Default for Limits {
    fn default() -> Self {
        Self {
            max_line_bytes: 4096,
            max_total_bytes: 64 * 1024 * 1024,
        }
    }
}
#[derive(Default, Debug, PartialEq, Eq)]
pub struct Report {
    pub lines: u64,
    pub valid: u64,
    pub malformed: u64,
    pub oversized: u64,
    pub info: u64,
    pub warnings: u64,
    pub errors: u64,
}
enum Line {
    End,
    Data,
    Oversized,
}
fn read_bounded<R: BufRead>(
    reader: &mut R,
    output: &mut Vec<u8>,
    limit: usize,
    total: &mut u64,
    total_limit: u64,
) -> io::Result<Line> {
    output.clear();
    let mut seen = false;
    let mut oversized = false;
    loop {
        let available = match reader.fill_buf() {
            Ok(bytes) => bytes,
            Err(error) if error.kind() == io::ErrorKind::Interrupted => continue,
            Err(error) => return Err(error),
        };
        if available.is_empty() {
            return Ok(if !seen {
                Line::End
            } else if oversized {
                Line::Oversized
            } else {
                Line::Data
            });
        }
        let newline = available.iter().position(|&b| b == b'\n');
        let take = newline.map_or(available.len(), |n| n + 1);
        *total = total
            .checked_add(take as u64)
            .filter(|&n| n <= total_limit)
            .ok_or_else(|| {
                io::Error::new(io::ErrorKind::InvalidData, "input byte limit exceeded")
            })?;
        let payload = if newline.is_some() { take - 1 } else { take };
        if !oversized {
            if payload > limit.saturating_sub(output.len()) {
                oversized = true;
                output.clear();
            } else {
                output.extend_from_slice(&available[..payload]);
            }
        }
        reader.consume(take);
        seen = true;
        if newline.is_some() {
            if oversized {
                return Ok(Line::Oversized);
            }
            if output.last() == Some(&b'\r') {
                output.pop();
            }
            return Ok(Line::Data);
        }
    }
}
/// At most `max_line_bytes` retained per line; an oversized line is drained.
/// Reader buffering is additional memory controlled by the caller.
pub fn analyze<R: BufRead>(reader: R, limits: Limits) -> io::Result<Report> {
    scan(reader, limits, None, &mut io::sink()).map(|result| result.summary)
}

/// Search valid records with a case-sensitive literal UTF-8 substring.
///
/// The query covers the complete normalized record (including its fields).
/// There is no case folding or Unicode normalization. Matching lines are written
/// immediately, with one LF terminator; CRLF input is normalized to LF.
/// Malformed and oversized lines are counted but never emitted. All valid
/// records contribute to the summary, whether or not they match.
///
/// Input/output errors abort the scan: the destination may already contain a
/// prefix, but no successful report is returned. The caller owns flushing.
/// ```
/// use log_detective::{search, Limits};
/// let mut output = Vec::new();
/// let result = search(&b"1 INFO api ready\n2 ERROR api retry\n"[..],
///     Limits::default(), "retry", &mut output)?;
/// assert_eq!(result.matched, 1);
/// assert_eq!(result.summary.valid, 2);
/// assert_eq!(output, b"2 ERROR api retry\n");
/// # Ok::<(), std::io::Error>(())
/// ```
pub fn search<R: BufRead, W: Write>(
    reader: R,
    limits: Limits,
    query: &str,
    output: &mut W,
) -> io::Result<SearchReport> {
    if query.is_empty() || query.len() > 4096 || query.chars().any(char::is_control) {
        return Err(io::Error::new(
            io::ErrorKind::InvalidInput,
            "query must be 1..=4096 UTF-8 bytes without control characters",
        ));
    }
    scan(reader, limits, Some(query), output)
}

/// Fixed-cardinality counters: no collection grows with services or matches.
#[derive(Debug, PartialEq, Eq)]
pub struct SearchReport {
    pub summary: Report,
    pub matched: u64,
}

fn scan<R: BufRead, W: Write>(
    mut reader: R,
    limits: Limits,
    query: Option<&str>,
    output: &mut W,
) -> io::Result<SearchReport> {
    if limits.max_line_bytes == 0
        || limits.max_line_bytes > 1024 * 1024
        || limits.max_total_bytes == 0
    {
        return Err(io::Error::new(
            io::ErrorKind::InvalidInput,
            "line limit must be 1..=1048576 and total limit positive",
        ));
    }
    let mut report = Report::default();
    let mut matched = 0;
    let mut line = Vec::new();
    let mut total = 0;
    loop {
        match read_bounded(
            &mut reader,
            &mut line,
            limits.max_line_bytes,
            &mut total,
            limits.max_total_bytes,
        )? {
            Line::End => {
                return Ok(SearchReport {
                    summary: report,
                    matched,
                });
            }
            Line::Oversized => {
                report.lines += 1;
                report.oversized += 1;
            }
            Line::Data => {
                report.lines += 1;
                let text = std::str::from_utf8(&line).map_err(|_| "invalid UTF-8");
                match text.and_then(parse_record) {
                    Err(_) => report.malformed += 1,
                    Ok(record) => {
                        report.valid += 1;
                        match record.level {
                            Level::Info => report.info += 1,
                            Level::Warn => report.warnings += 1,
                            Level::Error => report.errors += 1,
                        }
                        // A valid record was parsed from this same UTF-8 line.
                        // Searching its full text never indexes into a character.
                        if let (Some(query), Ok(text)) = (query, text)
                            && text.contains(query)
                        {
                            output.write_all(text.as_bytes())?;
                            output.write_all(b"\n")?;
                            matched += 1;
                        }
                    }
                }
            }
        }
    }
}

After a bounded line is complete, convert its bytes to UTF-8 and parse a borrowed Record. Increment exactly one of valid, malformed, or oversized for each counted line. For valid records, increment exactly one severity count. These relationships become testable invariants: lines equals valid plus malformed plus oversized, and valid equals info plus warnings plus errors. Accounting invariants catch missing branches even when individual example outputs look plausible.

Guided search increment: emit views before reusing storage

Literal search asks whether a sequence of characters appears inside a valid line. It does not interpret regular-expression symbols: a period matches a period. Add the SearchReport type after Report in src/lib.rs; it keeps the existing complete summary and a separate matched counter. Refactor the old loop into scan, taking an optional borrowed query and a Write destination. Keep analyze as a wrapper that supplies no query and io::sink(), a standard writer that discards bytes. This preserves the original analysis behavior while both entry points share one tested framing loop. The exact complete functions are in the source inclusion above; no omitted helper is needed.

In the valid-record branch, update the all-record counters first. Only then test text.contains(query). The if let pattern obtains a query and valid text, and its following && condition requires a match. A matching line is borrowed only until write_all finishes, so the next loop may safely reuse its byte buffer. W: Write means that the supplied value supports writing bytes, just as R: BufRead requires buffered reading. You will learn how these trait bounds support reusable libraries in Stage 2; here their concrete benefit is testing with a byte vector, a discard writer and a writer that deliberately fails. No collection of matching strings is needed.

Rust 1.99 str::contains accepts a string pattern and finds a matching string slice. Searching validated UTF-8 avoids slicing through a character. The policy is case-sensitive and performs no Unicode normalization: café with a precomposed é differs from cafe followed by a combining accent. A query must contain 1–4096 UTF-8 bytes and no control characters. Invalid and oversized records never reach the search writer. Valid messages already reject controls, including escape characters, but the tool does not redact secrets.

Write::write_all repeats partial writes until all bytes are written or an error occurs. A single write call may legally accept fewer bytes than requested. Write the normalized record, then LF. CRLF input becomes LF output, and an unterminated final record gains LF: this is normalized record output, not a raw byte-for-byte copy. If the reader, total budget or writer fails after several matches, those matches may already be visible. Return the error and treat that output as an incomplete prefix. Streaming publication is not an atomic transaction.

Replace the learner CLI's single-path argument handling in src/main.rs with the complete implementation below. args_os preserves native file paths. Only the query and positive decimal byte budget require Unicode text. Options precede the path; -- ends option recognition for a path beginning with a dash. The command line keeps its 4096-byte line bound. File reads use an explicit 8192-byte BufReader. The final flush must succeed before the CLI prints a success summary; a broken pipe is a failed scan with exit status 1. Failure to write a diagnostic cannot repair the original error, so main deliberately ignores that second error while retaining a failing exit status.

use std::{

const USAGE: &str = "usage: log-detective [--contains LITERAL] [--max-bytes N] [--] <file|->\n\
    Search is case-sensitive and emits valid matching records to stdout.\n\
    Search summary goes to stderr; without search, the summary goes to stdout.\n\
    N is a positive decimal byte budget, including discarded input; default 67108864.\n\
    Lines retain at most 4096 bytes. Use -- before a path beginning with '-'.";

#[derive(Debug)]
struct Options {
    path: OsString,
    query: Option<String>,
    limits: Limits,
}
#[derive(Debug)]
enum Command {
    Help,
    Run(Options),
}
fn invalid(message: &str) -> io::Error {
    io::Error::new(io::ErrorKind::InvalidInput, message)
}
fn parse_args(mut args: impl Iterator<Item = OsString>) -> io::Result<Command> {
    let mut query = None;
    let mut budget = None;
    while let Some(argument) = args.next() {
        if argument == "--help" && query.is_none() && budget.is_none() {
            return if args.next().is_none() {
                Ok(Command::Help)
            } else {
                Err(invalid("--help must be used alone"))
            };
        }
        if argument == "--contains" {
            if query.is_some() {
                return Err(invalid("--contains was supplied twice"));
            }
            let value = args
                .next()
                .ok_or_else(|| invalid("--contains needs a literal"))?;
            let value = value
                .into_string()
                .map_err(|_| invalid("query must be UTF-8"))?;
            if value.is_empty() || value.len() > 4096 || value.chars().any(char::is_control) {
                return Err(invalid(
                    "query must be 1..=4096 UTF-8 bytes without control characters",
                ));
            }
            query = Some(value);
        } else if argument == "--max-bytes" {
            if budget.is_some() {
                return Err(invalid("--max-bytes was supplied twice"));
            }
            let value = args
                .next()
                .ok_or_else(|| invalid("--max-bytes needs a positive integer"))?;
            let text = value
                .to_str()
                .ok_or_else(|| invalid("byte budget must be UTF-8 decimal digits"))?;
            if text.is_empty() || !text.bytes().all(|b| b.is_ascii_digit()) {
                return Err(invalid("byte budget must contain only decimal digits"));
            }
            budget = Some(
                text.parse::<u64>()
                    .ok()
                    .filter(|&n| n > 0)
                    .ok_or_else(|| invalid("byte budget must be 1..=18446744073709551615"))?,
            );
        } else {
            let path = if argument == "--" {
                args.next().ok_or_else(|| invalid("-- needs a file path"))?
            } else {
                if argument != "-" && argument.as_encoded_bytes().starts_with(b"-") {
                    return Err(invalid(
                        "unknown option; use -- before a path beginning with '-'",
                    ));
                }
                argument
            };
            if args.next().is_some() {
                return Err(invalid("expected one file path after the options"));
            }
            return Ok(Command::Run(Options {
                path,
                query,
                limits: Limits {
                    max_total_bytes: budget.unwrap_or(Limits::default().max_total_bytes),
                    ..Limits::default()
                },
            }));
        }
    }
    Err(invalid(USAGE))
}
fn write_summary(output: &mut impl Write, report: &Report) -> io::Result<()> {
    write!(
        output,
        "lines={} valid={} malformed={} oversized={} info={} warnings={} errors={}",
        report.lines,
        report.valid,
        report.malformed,
        report.oversized,
        report.info,
        report.warnings,
        report.errors
    )
}
fn process(reader: impl BufRead, options: &Options) -> io::Result<()> {
    let mut stdout = io::stdout().lock();
    if let Some(query) = &options.query {
        let report = search(reader, options.limits, query, &mut stdout)?;
        // Output failures, including a broken pipe, are errors. Do not print a
        // success summary before the matching records have been flushed.
        stdout.flush()?;
        let mut stderr = io::stderr().lock();
        write_summary(&mut stderr, &report.summary)?;
        writeln!(stderr, " matched={}", report.matched)?;
        stderr.flush()?;
    } else {
        let report = analyze(reader, options.limits)?;
        write_summary(&mut stdout, &report)?;
        writeln!(stdout)?;
        stdout.flush()?;
    }
    Ok(())
}
fn run() -> io::Result<()> {
    let options = match parse_args(std::env::args_os().skip(1))? {
        Command::Help => {
            let mut stdout = io::stdout().lock();
            writeln!(stdout, "{USAGE}")?;
            return stdout.flush();
        }
        Command::Run(options) => options,
    };
    if options.path == "-" {
        process(io::stdin().lock(), &options)
    } else {
        let file = File::open(&options.path).map_err(|error| {
            io::Error::new(error.kind(), format!("open {:?}: {error}", options.path))
        })?;
        process(BufReader::with_capacity(8192, file), &options)
    }
}
fn main() -> ExitCode {
    match run() {
        Ok(()) => ExitCode::SUCCESS,
        Err(error) => {
            // A failed diagnostic sink cannot repair the original failure.
            let _ = writeln!(io::stderr().lock(), "logs: {error}");
            ExitCode::FAILURE
        }
    }
}

The second command is a usage template: substitute an existing file. Its 10 GiB work budget is an explicit choice, not a 10 GiB allocation. All discarded bytes and line terminators count. A buffered reader may prefetch into its bounded buffer before the scanner detects budget exhaustion. The scanner stores one bounded line, a bounded query and a fixed number of counters. It therefore supports files larger than available memory, provided the reader and output destination also stream. The supplied generated-reader test exercises 67,109,888 bytes using one 1 KiB repeated record and a 257-byte reader buffer; it does not claim that this amount exceeded this computer's physical RAM or that RSS was measured.

Playbook: a visually identical word does not match

Observation: café matches a record copied from one producer but not a visually identical record from another. Hypothesis A: a two-byte é was split at a reader boundary. Hypothesis B: the producers used different Unicode sequences. First run the same bytes with capacities 1 and 32. The reference produces identical counts, weakening A. Then inspect the Rust string escapes in unicode_literal_matching_is_independent_of_chunk_boundaries: one contains a precomposed é and the other an e followed by a combining accent. Comparing those exact sequences supports B. The smallest sound action is to honor the declared literal contract and explain the difference. Adding normalization is a new requirement, not a buffering fix.

Predict a second failure: a writer accepts five bytes, then returns BrokenPipe. The output_failure_returns_error_instead_of_successful_report test checks that this is an error, not a successful one-match report. Intentional mistake: returning at the size boundary

In a learner copy, return Oversized as soon as retained bytes would cross the limit. With a long line followed by a valid record, the next call begins halfway through the rejected line. Your report may count several malformed fragments or lose the real next record. The fix is not to increase the default limit until the test passes. Restore the record-boundary protocol: drain the rejected physical line, then report one oversized record.

A separate mistake is calling read_to_string on the entire file and then iterating its lines. That can produce correct totals for small fixtures while violating the memory contract. Tests should exercise small reader buffer capacities, long lines, invalid bytes, and a final unterminated line. Memory claims also require code-level reasoning about allocation and retention; output equality alone cannot prove a bound.

Playbook: totals change with buffer size

Observation: the same bytes produce different counts when BufReader capacity changes from 1 to 4096. Hypothesis A: the record grammar depends on chunk boundaries. Hypothesis B: the implementation accidentally treats buffer chunks as complete lines. A distinguishing experiment uses a two-line fixed input and iterates capacities 1 through 32. Expected reference result: identical totals for every capacity. The grammar is defined by newline boundaries, so capacity-dependent results disprove a correct chunk-independent implementation.

Review, limits, and mastery

The recommended analyzer bounds retained bytes and total consumed input at the point of ingestion, with explicit rejected-record accounting. A whole-file immutable buffer would simplify borrowed long-lived views but would require a different, small-file resource contract. Reader buffering still adds memory beyond the retained line Vec; the caller controls that buffer. The total byte limit bounds processed input, not elapsed wall-clock time for a slow blocking reader.

Mastery means explaining why a huge line cannot make the retained line buffer grow without limit, why analysis resumes correctly afterward, and why counters remain consistent. The deterministic buffer-size sweep is finite evidence over selected inputs, not a proof for all streams. Pair it with an argument about every state transition, the injected read/write failure tests and a record of still-untested operating-system conditions. This is the first course project where the resource contract deserves as much attention as the numeric output.

Engineering decisions and evidence

Requirements and invariants

Retain at most the configured line payload, count each physical line once, drain oversized lines, propagate read/write failures and reject input beyond its total-byte budget. Summary categories partition all counted lines; severity counters partition valid records. Search matches are a subset of valid records. UTF-8 views never outlive the stable current line. Output already written may remain when a later operation fails.

Chosen design and concrete habits

The shared scan state machine uses fill_buf and consume. analyze supplies a discard writer with no query; search supplies a bounded literal and the caller's writer. Fixed counters avoid a service-name map with attacker-controlled cardinality. A parsed Record borrows its fields for immediate accounting, while str::contains searches the whole validated line without byte indexing. write_all handles short writes and returns ordinary failures. The CLI uses args_os for native paths, validates textual options, owns stdout flushing and reports success only after that flush.

Meaningful alternative and evolution threshold

A whole-file buffer is suitable only under a separately justified small-file memory contract. Raising --max-bytes changes the allowed work, not the retained-line bound. Regular expressions, normalized or case-insensitive Unicode matching require explicit semantics and may justify a maintained library. Per-service aggregation needs bounded cardinality. A blocking byte budget does not provide a wall-clock deadline. Atomic output publication would require a separate temporary-file and replacement contract; this tool deliberately exposes streaming prefix-on-error behavior.

Actual checks and remaining uncertainty

The search follow-up records unit, CLI, integration and documentation tests, strict Clippy, all-target checking and formatting. A generated reader processed 67,109,888 bytes from one 1 KiB record through a 257-byte reader, with all 65,537 records counted and matched. Unicode, partial output failures, a read error after emitted output, Interrupted retry and budget boundaries are tested. This supports the declared stream contract; it is not an RSS benchmark or proof for every input. Reader/writer storage and allocator overhead add memory. Independent review remains pending.
