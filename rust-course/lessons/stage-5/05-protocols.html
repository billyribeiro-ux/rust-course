Purpose: messages are an application decision

A chat user types “hello” once, but a TCP receiver is not promised one matching read. TCP supplies an ordered byte stream while a connection works. A read might receive one byte, two messages together, or an incomplete message followed by a disconnect. Framing is our rule for finding message boundaries inside that stream. Our application cannot delegate this rule to packet boundaries or the timing of writes.

Plain-English model

Imagine a parcel carrying a label with its payload size. Our frame has a four-byte, unsigned, big-endian length, followed by that many UTF-8 bytes. Big-endian means the most significant byte comes first: the prefix 00 00 00 02 describes two payload bytes. This analogy explains parsing only; TCP does not preserve parcels and does not promise delivery after a crash. A message is accepted only after every payload byte has arrived and validation succeeds. This protocol allows 1 through 1,024 bytes and rejects control characters. It is a deliberately small text protocol, not an Internet standard.

UTF-8 encodes Unicode characters using variable numbers of bytes. “é” has two UTF-8 bytes here. A Rust String::len() counts bytes, not what a reader perceives as characters. Checking the byte budget before allocating prevents a peer from requesting a four-gigabyte vector. Checking text after the bounded read prevents malformed UTF-8 from leaking into the domain model.

Predict before running

The example below feeds the bytes 00 00 00 02 C3 A9. Will it print one character, two characters, or an error? If the prefix is changed to three, does the missing byte become zero automatically? Explain your prediction before opening the answer.

Prediction explained

It prints é: 2 bytes. Declaring three bytes produces an unexpected end-of-file error because the reader must supply all three. The initialized vector does contain zeros initially, but read_exact does not report success for a partially filled payload.

Follow the unfamiliar operations

The slice reference is a reader over memory, so the example isolates decoding from actual networking. read_u32 decodes the prefix. The integer is bounded before becoming a vector length. read_exact loops internally until the requested buffer is full or an error occurs. String::from_utf8 validates encoding and takes ownership of the bytes. map_err changes an error into the protocol's I/O error category without pretending it was successful. The ? operator returns early on a failed step.

Intentional failure and first checkpoint

In your learner copy, implement a decoder that calls a single read for the whole payload and incorrectly treats the returned count as a complete message. This is a deliberate runtime logic defect, not a compiler failure. Reproduce it using the fragmented-frame test, then replace that operation with read_exact. Keep the maximum-length check before allocation. The reconstructed 01-framing library contains complete synchronous frame functions and fragmented-reader tests. projects/reference/p09-chat/src/lib.rs
//! A length-prefixed, bounded, local teaching chat service. No authentication/TLS.
use std::{io, sync::Arc, time::Duration};
use tokio::{
    io::{AsyncRead, AsyncReadExt, AsyncWrite, AsyncWriteExt},
    net::TcpListener,
    sync::{Semaphore, broadcast, watch},
    task::JoinSet,
    time::timeout,
};
pub const MAX_FRAME: usize = 1024;
/// A four-byte big-endian length followed by UTF-8 bytes. Empty frames are invalid.
pub async fn read_frame<R: AsyncRead + Unpin>(reader: &mut R) -> io::Result<String> {
    let len = reader.read_u32().await? as usize;
    if len == 0 || len > MAX_FRAME {
        return Err(io::Error::new(
            io::ErrorKind::InvalidData,
            "frame length outside 1..=1024",
        ));
    }
    let mut bytes = vec![0; len];
    reader.read_exact(&mut bytes).await?;
    let text = String::from_utf8(bytes)
        .map_err(|_| io::Error::new(io::ErrorKind::InvalidData, "invalid UTF-8"))?;
    if text.chars().any(|c| c.is_control()) {
        return Err(io::Error::new(
            io::ErrorKind::InvalidData,
            "control character",
        ));
    }
    Ok(text)
}
pub async fn write_frame<W: AsyncWrite + Unpin>(writer: &mut W, text: &str) -> io::Result<()> {
    if text.is_empty() || text.len() > MAX_FRAME || text.chars().any(|c| c.is_control()) {
        return Err(io::Error::new(
            io::ErrorKind::InvalidInput,
            "invalid frame length",
        ));
    }
    writer.write_u32(text.len() as u32).await?;
    writer.write_all(text.as_bytes()).await?;
    writer.flush().await
}
/// At most 32 clients and 32 retained messages. A lagging client is disconnected.
/// Shutdown aborts connection tasks: the protocol has no durable delivery promise.
/// A true watch value or closure of all senders requests shutdown; false is not a stop.
pub async fn serve(listener: TcpListener, mut stop: watch::Receiver<bool>) -> io::Result<()> {
    let permits = Arc::new(Semaphore::new(32));
    let (bus, _) = broadcast::channel::<String>(32);
    let mut clients = JoinSet::new();
    let result = loop {
        // Observe the state before waiting: a receiver may already hold true.
        if *stop.borrow_and_update() {
            break Ok(());
        }
        tokio::select! {
            changed=stop.changed()=>{if changed.is_err(){break Ok(());}},
            Some(_)=clients.join_next(), if !clients.is_empty()=>{},
            incoming=listener.accept()=> {
                let (stream,_) = match incoming {
                    Ok(connection) => connection,
                    Err(error) => break Err(error),
                };
                let Ok(permit)=permits.clone().try_acquire_owned() else { drop(stream); continue; };
                let sender=bus.clone(); let mut messages=bus.subscribe();
                clients.spawn(async move {
                    let _permit=permit;
                    let (mut read,mut write)=stream.into_split();
                    // Dedicated reader owns partially consumed frames across writes.
                    let mut reader=Box::pin(async move {
                        loop { let text=timeout(Duration::from_secs(30),read_frame(&mut read)).await.map_err(|_|io::Error::new(io::ErrorKind::TimedOut,"read deadline"))??;
                            let _=sender.send(text);
                        }
                        #[allow(unreachable_code)] Ok::<(),io::Error>(())
                    });
                    loop { tokio::select! {
                        _=&mut reader=>break,
                        message=messages.recv()=> {
                            let Ok(text)=message else { break; };
                            if !matches!(timeout(Duration::from_secs(2),write_frame(&mut write,&text)).await,Ok(Ok(()))) {break;}
                        }
                    }}
                });
            }
        }
    };
    clients.abort_all();
    while clients.join_next().await.is_some() {}
    result
}

mod tests {
    use super::*;
    #[tokio::test]
    async fn malformed_text_and_empty_frames_are_rejected() {
        for fixture in [vec![0, 0, 0, 0], vec![0, 0, 0, 1, 255], vec![0, 0, 0, 1, 0]] {
            assert_eq!(
                read_frame(&mut fixture.as_slice())
                    .await
                    .unwrap_err()
                    .kind(),
                io::ErrorKind::InvalidData
            );
        }
        let mut output = Vec::new();
        assert!(write_frame(&mut output, "line\nbreak").await.is_err());
        assert!(output.is_empty());
    }
    #[tokio::test]
    async fn fragmented_frame_and_utf8() {
        let (mut tx, mut rx) = tokio::io::duplex(64);
        let task = tokio::spawn(async move {
            for b in [0, 0, 0, 2, 0xc3, 0xa9] {
                tx.write_all(&[b]).await.unwrap();
                tokio::task::yield_now().await;
            }
        });
        assert_eq!(read_frame(&mut rx).await.unwrap(), "é");
        task.await.unwrap();
    }
    #[tokio::test]
    async fn coalesced_frames_obey_the_exact_byte_boundary() {
        let maximum = "é".repeat(MAX_FRAME / 2);
        assert_eq!(maximum.len(), MAX_FRAME);
        let mut wire = Vec::new();
        write_frame(&mut wire, &maximum).await.unwrap();
        write_frame(&mut wire, "after").await.unwrap();
        let mut input = wire.as_slice();
        assert_eq!(read_frame(&mut input).await.unwrap(), maximum);
        assert_eq!(read_frame(&mut input).await.unwrap(), "after");
        assert!(input.is_empty());

        let mut output = vec![99];
        assert_eq!(
            write_frame(&mut output, &format!("{maximum}x"))
                .await
                .unwrap_err()
                .kind(),
            io::ErrorKind::InvalidInput
        );
        assert_eq!(output, [99]); // Validation precedes even the prefix write.
        let header = (MAX_FRAME as u32 + 1).to_be_bytes();
        assert_eq!(
            read_frame(&mut header.as_slice()).await.unwrap_err().kind(),
            io::ErrorKind::InvalidData
        );
    }
    #[tokio::test]
    async fn retaining_the_same_future_preserves_partial_prefix_progress() {
        use std::{future::Future, task::Poll};
        let (mut tx, mut rx) = tokio::io::duplex(8);
        tx.write_all(&[0, 0]).await.unwrap();
        let mut frame = Box::pin(read_frame(&mut rx));
        std::future::poll_fn(|context| {
            assert!(frame.as_mut().poll(context).is_pending());
            Poll::Ready(())
        })
        .await;
        // Other work can finish while the pinned decoder retains its first two
        // bytes. This checks the ownership pattern, not a timed socket schedule.
        tx.write_all(&[0, 2, 0xc3, 0xa9]).await.unwrap();
        assert_eq!(frame.await.unwrap(), "é");
    }
    #[tokio::test]
    async fn oversized_rejected_before_body() {
        let mut bytes = &[0, 0, 8, 0][..];
        assert_eq!(
            read_frame(&mut bytes).await.unwrap_err().kind(),
            io::ErrorKind::InvalidData
        );
    }
    #[tokio::test]
    async fn truncated_body_fails() {
        let mut bytes = &[0, 0, 0, 3, b'a'][..];
        assert_eq!(
            read_frame(&mut bytes).await.unwrap_err().kind(),
            io::ErrorKind::UnexpectedEof
        );
    }
    #[tokio::test]
    async fn lag_is_visible() {
        let (tx, mut rx) = broadcast::channel(2);
        for n in 0..3 {
            tx.send(n).unwrap();
        }
        assert!(matches!(
            rx.recv().await,
            Err(broadcast::error::RecvError::Lagged(1))
        ));
    }
    #[tokio::test]
    async fn loopback_and_shutdown() {
        let listener = TcpListener::bind("127.0.0.1:0").await.unwrap();
        let addr = listener.local_addr().unwrap();
        let (tx, rx) = watch::channel(false);
        let server = tokio::spawn(serve(listener, rx));
        let mut client = tokio::net::TcpStream::connect(addr).await.unwrap();
        write_frame(&mut client, "hello").await.unwrap();
        assert_eq!(
            timeout(Duration::from_secs(2), read_frame(&mut client))
                .await
                .unwrap()
                .unwrap(),
            "hello"
        );
        tx.send(true).unwrap();
        server.await.unwrap().unwrap();
    }
    #[tokio::test]
    async fn shutdown_already_requested_does_not_wait_for_a_second_change() {
        let listener = TcpListener::bind("127.0.0.1:0").await.unwrap();
        let (_sender, receiver) = watch::channel(true);
        timeout(Duration::from_secs(2), serve(listener, receiver))
            .await
            .expect("an already-requested stop must complete")
            .unwrap();
    }
    #[tokio::test]
    async fn false_notifications_do_not_stop_and_sender_drop_does() {
        let listener = TcpListener::bind("127.0.0.1:0").await.unwrap();
        let address = listener.local_addr().unwrap();
        let (sender, receiver) = watch::channel(false);
        let server = tokio::spawn(serve(listener, receiver));
        let mut client = tokio::net::TcpStream::connect(address).await.unwrap();
        for text in ["before", "after"] {
            sender.send(false).unwrap();
            write_frame(&mut client, text).await.unwrap();
            assert_eq!(
                timeout(Duration::from_secs(2), read_frame(&mut client))
                    .await
                    .unwrap()
                    .unwrap(),
                text
            );
        }
        drop(sender);
        timeout(Duration::from_secs(2), server)
            .await
            .unwrap()
            .unwrap()
            .unwrap();
    }

Independent practice

Add tests for a zero-length prefix, a 1,024-byte ASCII payload, an invalid UTF-8 sequence, and a control character. Decide whether line breaks should be legal inside a future chat message. Document the rule before changing both writer and reader validation. Explain why a character-count limit alone does not enforce a wire-byte limit.

Hint 1: identify the boundary

Separate prefix validation from content validation; invalid length should fail before reading a body.

Hint 2: build a fixture

A byte slice implements the reader interface. Prefixes and malformed payloads need no network connection.

Worked approach

Use [0,0,0,0] for empty input and a length of one followed by FF for invalid UTF-8. For the boundary success case, construct 1,024 ASCII bytes and a big-endian prefix. Change the writer to share the same validation helper if you need symmetrical validation; otherwise document that the receiver remains authoritative.

Review and evidence

A deliberate review defect is repeatedly appending reads until “nothing else arrives.” Timing is not framing. The idiomatic design expresses exact lengths and typed errors. Space is O(maximum frame size), and decoding time is O(payload bytes). Tests establish behavior for selected fragments and invalid inputs; they do not prove resistance to every network attack. Run mise exec -- cargo test -p p09-chat and inspect the named boundary tests.

Playbook investigation

Observation: short local messages pass, but messages sometimes lose their first character under load. A plausible guess is a UTF-8 bug. Distinguishing experiment: send ASCII only while splitting the four prefix bytes across separate writes. The same failure disproves the UTF-8 hypothesis. Instrument bytes consumed, not just final text. Another possible cause is cancelling a partially consumed frame read in a select loop and starting over. The server keeps one reader future alive across outgoing writes. That fix preserves decoder progress; it does not create reliable delivery after disconnection.

//! Bounded synchronous framing checkpoint, before Tokio or a chat service.
use std::io::{self, Read, Write};
pub const MAX_FRAME: usize = 1024;
fn invalid(reason: &'static str) -> io::Error {
    io::Error::new(io::ErrorKind::InvalidData, reason)
}
pub fn encode(mut output: impl Write, text: &str) -> io::Result<()> {
    if text.is_empty() || text.len() > MAX_FRAME || text.chars().any(char::is_control) {
        return Err(invalid("invalid frame text"));
    }
    output.write_all(&(text.len() as u32).to_be_bytes())?;
    output.write_all(text.as_bytes())
}
pub fn decode(mut input: impl Read) -> io::Result<Option<String>> {
    let mut header = [0; 4];
    match input.read_exact(&mut header[..1]) {
        Ok(()) => {}
        Err(error) if error.kind() == io::ErrorKind::UnexpectedEof => return Ok(None),
        Err(error) => return Err(error),
    }
    input.read_exact(&mut header[1..])?;
    let length = u32::from_be_bytes(header) as usize;
    if !(1..=MAX_FRAME).contains(&length) {
        return Err(invalid("frame length outside budget"));
    }
    let mut payload = vec![0; length];
    input.read_exact(&mut payload)?;
    let text = String::from_utf8(payload).map_err(|_| invalid("invalid UTF-8"))?;
    if text.chars().any(char::is_control) {
        return Err(invalid("control characters"));
    }
    Ok(Some(text))
}

mod tests {
    use super::*;
    struct Fragmented<'a>(&'a [u8]);
    impl Read for Fragmented<'_> {
        fn read(&mut self, output: &mut [u8]) -> io::Result<usize> {
            let take = output.len().min(1);
            self.0.read(&mut output[..take])
        }
    }
    #[test]
    fn fragmented_utf8_roundtrip() {
        let mut bytes = Vec::new();
        encode(&mut bytes, "café").unwrap();
        assert_eq!(&bytes[..4], &[0, 0, 0, 5]);
        assert_eq!(decode(Fragmented(&bytes)).unwrap(), Some("café".into()));
    }
    #[test]
    fn clean_eof_differs_from_truncation() {
        assert_eq!(decode(&[][..]).unwrap(), None);
        assert_eq!(
            decode(&[0, 0][..]).unwrap_err().kind(),
            io::ErrorKind::UnexpectedEof
        );
        assert_eq!(
            decode(&[0, 0, 0, 2, b'x'][..]).unwrap_err().kind(),
            io::ErrorKind::UnexpectedEof
        );
    }
    #[test]
    fn reject_before_unbounded_allocation() {
        assert!(decode(&[255, 255, 255, 255][..]).is_err());
        assert!(decode(&[0, 0, 0, 1, 255][..]).is_err());
        assert!(decode(&[0, 0, 0, 1, b'\n'][..]).is_err());
        assert!(encode(Vec::new(), "hello\n").is_err());
    }
