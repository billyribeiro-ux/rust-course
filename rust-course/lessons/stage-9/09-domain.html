Purpose and independent specification

The capstone is a research and simulated paper-trading workbench. There is no real-money execution, broker connection, paid feed, or claim to model an exchange accurately. Its first milestone is a domain engine that behaves predictably without HTTP, a browser, or a database. Start by implementing the following invariants: cash cannot become negative, holdings cannot become negative, a rejected order changes no state, a repeated logical order does not trade twice, and replaying accepted events in the same order reconstructs the same state.

Plain-English model: values with meaning

A number needs a unit. The engine stores prices and cash as signed64-bit integer cents and quantities as whole units. It deliberately excludes fractional shares, commissions, taxes, multiple currencies, partial fills, order-book depth, and realistic market impact. Buying three units at125 cents costs375 cents exactly within this model. Floating-point arithmetic could approximate many prices but would not express the intended fixed-cent invariant directly.

Integer arithmetic is not magically safe. A valid per-item price multiplied by a large quantity can overflow. Validate bounds and use checked multiplication before mutation. Selling also checks cash addition. The current price cap is100,000,000 cents, quantity is1 through10,000, and the starting simulated balance is1,000,000 cents. These are teaching limits, not financial recommendations. Extending to fractional quantities requires an explicit scale and rounding rule; merely replacing i64 with f64 loses the original contract.

Prediction

A tick sets RUST to125 cents. Order o1 buys three units. The client loses its response and submits exactly o1 again. What is the final cash? Now imagine the retry reuses o1 but asks for four units.

Answer

Cash is999,625 cents and holdings are3. The identical retry returns applied:false. Reusing the ID with a different quantity is a conflict, not an instruction to edit history. Generating a new ID for every automatic retry would defeat this rule and create another purchase.

Small runnable example

The library owns all domain behavior. This example intentionally uses unwrap only for hard-coded fixtures that are expected to satisfy the invariants; API handlers must handle untrusted input errors explicitly.

Read the validation path

Event distinguishes a tick, an order, and a watchlist change. A tick has a unique event ID, symbol, integer price, and per-symbol sequence. Sequence determines accepted market order in this lab; wall-clock timestamps are absent because the engine does not make freshness or physical-time claims. A repeated event ID with identical content is a retry. A new ID with a sequence no greater than the last accepted sequence is out of order and rejected. A replay system that accepts late events would need a different policy, such as a bounded reorder buffer and an explicit finalization watermark.

validate only reads current state. It checks identity reuse, domain limits, quotes, arithmetic, cash, holdings, and the10,000-event session budget. apply calls validation before changing any field. The store later uses the same read-only validation before writing the event. Because one mutation owns the state exclusively, no other operation can change the checked facts between validation and application. That ownership argument would need revision if you split one account across multiple writers.

Guided checkpoint

Implement Tick, Side, Order, Event, and a minimal Engine containing cash, quotes, positions, and order IDs. Add duplicate-order and insufficient-cash tests before any persistence. Then implement snapshot as a read model: a representation for display, not the authority that accepts orders. The reference stores fills by logical order ID for lookup and separately tracks the latest100 accepted IDs in a bounded deque. Snapshots therefore return newest accepted fills first, independent of the spelling of an ID. A regression uses IDs beginning z, a, and m to prove that alphabetic order is not mistaken for acceptance order. This is still a recent read model, not an unbounded lifetime-history endpoint.

fn symbol(s: &str) -> bool {
    !s.is_empty() && s.len() <= 8 && s.bytes().all(|b| b.is_ascii_uppercase())
}
fn identifier(s: &str) -> bool {
    !s.is_empty()
        && s.len() <= 80
        && s.bytes()
            .all(|b| b.is_ascii_alphanumeric() || b"-_".contains(&b))
}
impl Engine {
    fn validate_tick(&self, t: &Tick) -> Result<bool, &'static str> {
        if let Some(old) = self.seen.get(&t.event_id) {
            return if old == t {
                Ok(false)
            } else {
                Err("event id conflict")
            };
        }
        if !identifier(&t.event_id)
            || !symbol(&t.symbol)
            || t.price_cents <= 0
            || t.price_cents > 100_000_000
        {
            return Err("invalid tick");
        }
        if self
            .quotes
            .get(&t.symbol)
            .is_some_and(|q| t.sequence <= q.sequence)
        {
            return Err("out-of-order tick");
        }
        if !self.quotes.contains_key(&t.symbol) && self.quotes.len() >= 32 {
            return Err("symbol budget");
        }
        Ok(true)
    }
    /// Validation is read-only. `false` denotes an exact retry already applied.
    pub fn validate(&self, event: &Event) -> Result<bool, &'static str> {
        match event {
            Event::Tick(t) => {
                if !self.validate_tick(t)? {
                    return Ok(false);
                }
            }
            Event::Order(o) => {
                if let Some(fill) = self.fills.get(&o.order_id) {
                    return if fill.symbol == o.symbol
                        && fill.quantity == o.quantity
                        && fill.side == o.side
                    {
                        Ok(false)
                    } else {
                        Err("order id conflict")
                    };
                }
                if !identifier(&o.order_id)
                    || !symbol(&o.symbol)
                    || !(1..=10_000).contains(&o.quantity)
                {
                    return Err("invalid order");
                }
                let quote = self.quotes.get(&o.symbol).ok_or("quote required")?;
                let cost = quote
                    .price_cents
                    .checked_mul(o.quantity)
                    .ok_or("cost overflow")?;
                let held = *self.positions.get(&o.symbol).unwrap_or(&0);
                match o.side {
                    Side::Buy => {
                        if cost > self.cash {
                            return Err("insufficient simulated cash");
                        }
                        held.checked_add(o.quantity).ok_or("position overflow")?;
                    }
                    Side::Sell => {
                        if held < o.quantity {
                            return Err("insufficient position");
                        }
                        self.cash.checked_add(cost).ok_or("cash overflow")?;
                    }
                }
            }
            Event::ScheduleReplay(spec) => {
                if let Some(job) = self.jobs.get(&spec.job_id) {
                    return if job.spec == *spec {
                        Ok(false)
                    } else {
                        Err("job id conflict")
                    };
                }
                if !identifier(&spec.job_id)
                    || spec.ticks.is_empty()
                    || spec.ticks.len() > 64
                    || self.jobs.len() >= 16
                {
                    return Err("replay job budget or identity");
                }
                for tick in &spec.ticks {
                    if !identifier(&tick.event_id)
                        || !symbol(&tick.symbol)
                        || tick.price_cents <= 0
                        || tick.price_cents > 100_000_000
                    {
                        return Err("invalid replay tick");
                    }
                }
                // Reserve enough event slots for already queued work plus this job and cancellation.
                let pending: usize = self
                    .jobs
                    .values()
                    .filter(|j| j.active())
                    .map(|j| j.spec.ticks.len() - j.next)
                    .sum();
                if self.events + (pending + spec.ticks.len() + 32) as u64 >= 10_000 {
                    return Err("insufficient replay event budget");
                }
            }
            Event::ReplayStep { job_id, index } => {
                let job = self.jobs.get(job_id).ok_or("job not found")?;
                if *index < job.next {
                    return Ok(false);
                }
                if !job.active() || *index != job.next {
                    return Err("job no longer runnable or cursor conflict");
                }
                let tick = &job.spec.ticks[*index];
                self.validate_tick(tick)?;
            }
            Event::CancelReplay { job_id } => {
                let job = self.jobs.get(job_id).ok_or("job not found")?;
                if job.status == replay::ReplayStatus::Cancelled {
                    return Ok(false);
                }
                if !job.active() {
                    return Err("job already terminal");
                }
            }
            Event::FailReplay { job_id, reason } => {
                if reason.len() > 100 {
                    return Err("failure reason budget");
                }
                if !self.jobs.get(job_id).is_some_and(|j| j.active()) {
                    return Err("job no longer runnable");
                }
            }
            Event::Watchlist(symbols) => {
                if symbols.len() > 32 || symbols.iter().any(|s| !symbol(s)) {
                    return Err("invalid watchlist");
                }
                let unique: std::collections::BTreeSet<_> = symbols.iter().collect();
                if unique.len() != symbols.len() {
                    return Err("duplicate watchlist symbol");
                }
            }
        }
        if self.events >= 10_000 {
            return Err("event budget reached; archive session");
        }
        if matches!(
            event,
            Event::Tick(_) | Event::Order(_) | Event::Watchlist(_)
        ) {
            let reserved: usize = self
                .jobs
                .values()
                .filter(|job| job.active())
                .map(|job| job.spec.ticks.len() - job.next)
                .sum();
            if self.events + reserved as u64 >= 10_000 {
                return Err("remaining event capacity reserved for accepted replay jobs");
            }
        }
        Ok(true)
    }
    pub fn apply(&mut self, event: Event) -> Result<bool, &'static str> {
        if !self.validate(&event)? {
            return Ok(false);
        }
        match event {
            Event::Tick(t) => self.accept_tick(t),
            Event::Order(o) => {
                let price = self.quotes[&o.symbol].price_cents;
                let cost = price * o.quantity;
                let held = self.positions.entry(o.symbol.clone()).or_default();
                match o.side {
                    Side::Buy => {
                        self.cash -= cost;
                        *held += o.quantity;
                    }
                    Side::Sell => {
                        self.cash += cost;
                        *held -= o.quantity;
                    }
                }
                let accepted_id = o.order_id.clone();
                self.fills.insert(
                    o.order_id.clone(),
                    Fill {
                        order_id: o.order_id,
                        symbol: o.symbol,
                        side: o.side,
                        quantity: o.quantity,
                        price_cents: price,
                    },
                );
                self.recent_orders.push_back(accepted_id);
                if self.recent_orders.len() > 100 {
                    self.recent_orders.pop_front();
                }
            }
            Event::Watchlist(symbols) => self.watchlist = symbols,
            Event::ScheduleReplay(spec) => {
                self.jobs.insert(
                    spec.job_id.clone(),
                    replay::ReplayJob {
                        spec,
                        next: 0,
                        status: replay::ReplayStatus::Queued,
                        error: None,
                    },
                );
            }
            Event::ReplayStep { job_id, index } => {
                let tick = self.jobs[&job_id].spec.ticks[index].clone();
                if self.validate_tick(&tick)? {
                    self.accept_tick(tick);
                }
                let job = self
                    .jobs
                    .get_mut(&job_id)
                    .expect("validated job exists under exclusive ownership");
                job.next += 1;
                job.status = if job.next == job.spec.ticks.len() {
                    replay::ReplayStatus::Completed
                } else {
                    replay::ReplayStatus::Running
                };
            }
            Event::CancelReplay { job_id } => {
                self.jobs
                    .get_mut(&job_id)
                    .expect("validated job exists")
                    .status = replay::ReplayStatus::Cancelled;
            }
            Event::FailReplay { job_id, reason } => {
                let job = self.jobs.get_mut(&job_id).expect("validated job exists");
                job.status = replay::ReplayStatus::Failed;
                job.error = Some(reason);
            }
        }
        self.events += 1;
        Ok(true)
    }
    fn accept_tick(&mut self, t: Tick) {
        self.history.push_back(replay::ChartPoint {
            event_position: self.events + 1,
            symbol: t.symbol.clone(),
            price_cents: t.price_cents,
            sequence: t.sequence,
        });
        if self.history.len() > 1024 {
            self.history.pop_front();
        }
        self.quotes.insert(
            t.symbol.clone(),
            Quote {
                symbol: t.symbol.clone(),
                price_cents: t.price_cents,
                sequence: t.sequence,
            },
        );
        self.seen.insert(t.event_id.clone(), t);
    }
    pub fn fill(&self, id: &str) -> Option<&Fill> {
        self.fills.get(id)
    }
    pub fn snapshot(&self) -> Snapshot {
        Snapshot {
            simulated: true,
            cash_cents: self.cash,
            quotes: self.quotes.values().cloned().collect(),
            positions: self
                .positions
                .iter()
                .map(|(s, q)| Position {
                    symbol: s.clone(),
                    quantity: *q,
                })
                .collect(),
            orders: self
                .recent_orders
                .iter()
                .rev()
                .filter_map(|id| self.fills.get(id))
                .cloned()
                .collect(),
            watchlist: self.watchlist.clone(),
            events: self.events,
        }
    }
}
/// Distinguishes a rejected command from identity conflicts and uncertain storage outcomes.
#[derive(Debug)]
pub enum CommitError {
    Rejected(&'static str),
    Conflict(&'static str),
    Storage(String),
}
impl std::fmt::Display for CommitError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            Self::Rejected(reason) | Self::Conflict(reason) => f.write_str(reason),
            Self::Storage(reason) => f.write_str(reason),
        }
    }
}
impl std::error::Error for CommitError {}
impl CommitError {
    fn validation(reason: &'static str) -> Self {
        match reason {
            "event id conflict" | "order id conflict" | "job id conflict" => Self::Conflict(reason),
            _ => Self::Rejected(reason),
        }
    }
}
/// The authoritative engine cannot be mutated without journal persistence by callers.
///
/// ```compile_fail,E0616
/// use p16_workbench::{Store, Event};
/// fn bypass_persistence(store: &mut Store) {
///     store.engine.apply(Event::Watchlist(vec![]));
/// }
/// ```
pub struct Store {
    pub(crate) engine: Engine,
    file: File,
    poisoned: bool,
    records: u64,
}
impl Store {
    /// A single process owns this file. No cross-process locking; do not start two writers.
    /// sync_data precedes success. Creation-directory durability and torn-record repair are not promised.
    pub fn open(path: &Path) -> io::Result<Self> {
        let file = OpenOptions::new()
            .create(true)
            .append(true)
            .read(true)
            .open(path)?;
        let mut engine = Engine::default();
        let mut reader = BufReader::new(file.try_clone()?);
        let mut line = Vec::new();
        let mut records = 0;
        loop {
            line.clear();
            let read = reader.by_ref().take(16385).read_until(b'\n', &mut line)?;
            if read == 0 {
                break;
            }
            records += 1;
            if records > 10_000 {
                return Err(io::Error::new(io::ErrorKind::InvalidData, "record budget"));
            }
            if read > 16384 || line.last() != Some(&b'\n') {
                return Err(io::Error::new(
                    io::ErrorKind::InvalidData,
                    "oversized or incomplete record; preserve file for recovery",
                ));
            }
            let record: Record = serde_json::from_slice(&line)
                .map_err(|e| io::Error::new(io::ErrorKind::InvalidData, e))?;
            if !matches!(record.version, 1 | 2)
                || (record.version == 2 && record.position != Some(records))
                || (record.version == 1 && record.position.is_some())
            {
                return Err(io::Error::new(
                    io::ErrorKind::InvalidData,
                    "unknown record version or non-contiguous journal position",
                ));
            }
            let applied = engine
                .apply(record.event)
                .map_err(|e| io::Error::new(io::ErrorKind::InvalidData, e))?;
            if !applied {
                return Err(io::Error::new(
                    io::ErrorKind::InvalidData,
                    "duplicate logical command in journal",
                ));
            }
        }
        Ok(Self {
            engine,
            file,
            poisoned: false,
            records,
        })
    }
    pub fn snapshot(&self) -> Snapshot {
        self.engine.snapshot()
    }
    pub fn commit(&mut self, event: Event) -> Result<bool, CommitError> {
        if self.poisoned {
            return Err(CommitError::Storage(
                "storage uncertain; stop and inspect journal".into(),
            ));
        }
        if !self
            .engine
            .validate(&event)
            .map_err(CommitError::validation)?
        {
            return Ok(false);
        }
        if self.records >= 10_000 {
            return Err(CommitError::Rejected("physical journal record budget"));
        }
        let mut bytes = serde_json::to_vec(&Record {
            version: 2,
            position: Some(self.records + 1),
            event: event.clone(),
        })
        .map_err(|e| CommitError::Storage(format!("encoding failed before append: {e}")))?;
        bytes.push(b'\n');
        if bytes.len() > 16384 {
            return Err(CommitError::Rejected("journal record budget"));
        }
        if let Err(error) = self
            .file
            .write_all(&bytes)
            .and_then(|()| self.file.sync_data())
        {
            self.poisoned = true;
            return Err(CommitError::Storage(format!("storage uncertain: {error}")));
        }
        self.records += 1;
        match self.engine.apply(event) {
            Ok(true) => Ok(true),
            result => {
                self.poisoned = true;
                Err(CommitError::Storage(format!(
                    "durable record could not be applied consistently: {result:?}"
                )))
            }
        }
    }
}

mod tests {
    use super::*;
    fn tick(id: &str, seq: u64) -> Event {

        let mut e = Engine::default();
        assert!(e.apply(tick("t1", 1)).unwrap());
        assert!(!e.apply(tick("t1", 1)).unwrap());
        assert!(e.apply(tick("t1", 2)).is_err());
        assert!(e.apply(tick("old", 0)).is_err());
        e.apply(buy("o1", 3)).unwrap();
        assert!(!e.apply(buy("o1", 3)).unwrap());
        assert!(e.apply(buy("o1", 4)).is_err());
        assert_eq!(e.snapshot().cash_cents, 999625);
        assert_eq!(e.snapshot().positions[0].quantity, 3);
    }
    #[test]
    fn rejected_order_is_atomic() {
        let mut e = Engine::default();
        e.apply(tick("t", 1)).unwrap();
        let before = e.snapshot();
        assert!(e.apply(buy("huge", 10000)).is_err());
        assert_eq!(before, e.snapshot());
    }
    #[test]
    fn buy_sell_conserves_cash_without_fees() {
        for quantity in 1..500 {
            let mut e = Engine::default();
            e.apply(tick("t", 1)).unwrap();
            e.apply(buy("b", quantity)).unwrap();
            e.apply(Event::Order(Order {
                order_id: "s".into(),
                symbol: "RUST".into(),
                side: Side::Sell,
                quantity,
            }))
            .unwrap();
            assert_eq!(e.snapshot().cash_cents, 1_000_000);
            assert_eq!(e.snapshot().positions[0].quantity, 0);
        }
    }
    #[test]
    fn restart_replays_and_truncated_tail_fails() {
        let path = std::env::temp_dir().join(format!(
            "course-workbench-{}-{}.jsonl",
            std::process::id(),

                .as_nanos()

            s.commit(tick("t", 1)).unwrap();
            s.commit(buy("b", 5)).unwrap();
            s.engine.snapshot()

        let mut f = OpenOptions::new().append(true).open(&path).unwrap();
        f.write_all(b"{incomplete").unwrap();
        drop(f);
        assert!(Store::open(&path).is_err());
        std::fs::remove_file(path).unwrap();
    }

Deliberate mistake

Move cash subtraction before checking whether enough cash exists. An oversized order now returns an error after corrupting state. The rejected-order atomicity test must compare the complete snapshot before and after. Checking only the returned error would miss the defect. Restore validation-before-mutation. Next remove order-ID deduplication and observe the retry test changing holdings twice.

Independent practice

Add a fee of one cent per order, charged once for an accepted logical order. Decide how sells behave when proceeds are smaller than the fee, whether a zero-position entry remains visible, and whether an exact retry returns the original fill or only an applied flag. Write these decisions as acceptance criteria before changing code.

Hint 1

The fee belongs to the logical command's effect, not to the number of HTTP attempts.

Hint 2

Compute all post-operation values with checked arithmetic before committing any field.

Reference reasoning

For a buy, checked cost plus fee must fit available cash. For a sell, define net proceeds and reject any unsupported negative result before changing holdings. Persist the fee semantics or event version so old events replay with their original meaning. Returning the persisted fill on retries is often clearer than recomputing a price from the current quote.

//! Synthetic single-symbol, in-memory order domain checkpoint. No market access.
//! Integer cents and whole shares only; no persistence, jobs, chart, or HTTP yet.
use std::collections::BTreeMap;
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Side {
    Buy,
    Sell,
}
#[derive(Debug, Clone, PartialEq, Eq)]
struct Accepted {
    side: Side,
    quantity: i64,
    price: i64,
}
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Engine {
    cash: i64,
    shares: i64,
    quote: Option<(u64, i64)>,
    orders: BTreeMap<String, Accepted>,
}
impl Default for Engine {
    fn default() -> Self {
        Self {
            cash: 1_000_000,
            shares: 0,
            quote: None,
            orders: BTreeMap::new(),
        }
    }
}
impl Engine {
    pub fn tick(&mut self, sequence: u64, price: i64) -> Result<(), &'static str> {
        if price <= 0 || self.quote.is_some_and(|(old, _)| sequence <= old) {
            return Err("invalid or out-of-order tick");
        }
        self.quote = Some((sequence, price));
        Ok(())
    }
    pub fn order(&mut self, id: &str, side: Side, quantity: i64) -> Result<bool, &'static str> {
        if id.is_empty() || id.len() > 64 || quantity <= 0 {
            return Err("invalid order");
        }
        if let Some(old) = self.orders.get(id) {
            return if old.side == side && old.quantity == quantity {
                Ok(false)
            } else {
                Err("identity conflict")
            };
        }
        if self.orders.len() >= 64 {
            return Err("retained order budget");
        }
        let price = self.quote.ok_or("missing quote")?.1;
        let cost = price.checked_mul(quantity).ok_or("cost overflow")?;
        let (cash, shares) = match side {
            Side::Buy => (
                self.cash
                    .checked_sub(cost)
                    .filter(|v| *v >= 0)
                    .ok_or("insufficient cash")?,
                self.shares
                    .checked_add(quantity)
                    .ok_or("position overflow")?,
            ),
            Side::Sell => (
                self.cash.checked_add(cost).ok_or("cash overflow")?,
                self.shares
                    .checked_sub(quantity)
                    .filter(|v| *v >= 0)
                    .ok_or("insufficient shares")?,
            ),
        };
        // All fallible domain checks precede this mutation boundary.
        self.orders.insert(
            id.into(),
            Accepted {
                side,
                quantity,
                price,
            },
        );
        self.cash = cash;
        self.shares = shares;
        Ok(true)
    }
    pub fn balances(&self) -> (i64, i64) {
        (self.cash, self.shares)
    }
    pub fn accepted_price(&self, id: &str) -> Option<i64> {
        self.orders.get(id).map(|a| a.price)
    }
}
