Design an append-only record protocol

Implement bounded binary records, exact checksums, tombstones and replayable state transitions.

Purpose: let a process reconstruct its past

An in-memory map forgets everything when the process ends. The first storage design we will study records operations as an append-only sequence. A put records a key and value; a delete records a key and a deletion marker. Restart replays operations in order to reconstruct the latest map. This is intentionally a small single-writer design. It has no transactions across multiple keys, no multi-process reader snapshots, no indexes on disk, and no replication. Those omissions keep the state transitions visible enough to reason about rather than hiding them behind a database library.

Model: format bytes are a public contract

A KV01 record starts with four magic bytes, a little-endian 32-bit key length, a little-endian 32-bit value length, and a 32-bit CRC. Payload bytes follow: key first, then value. The reserved value length u32::MAX means deletion; a length of zero means a present empty value. Key lengths are one through 4096, and values have a one-megabyte maximum. The decoder checks those limits before allocating a payload. Integer widths and byte order are explicit because a file may outlive the compiler process that produced it. A native-memory representation is not a stable file format.

//! Single-writer educational log store. CRC checks complete declared records, not tampering.
//! An incomplete declared suffix is discarded; bounded length damage can look incomplete.
//! Successful writes call sync_all; hardware/filesystem power-loss guarantees vary.
use std::{
    collections::BTreeMap,
    fs::{self, File, OpenOptions},
    io::{self, Read, Write},
    path::{Path, PathBuf},
};

const MAGIC: &[u8; 4] = b"KV01";
const HEADER: usize = 16;
pub const MAX_KEY: usize = 4096;
pub const MAX_VALUE: usize = 1_048_576;

fn invalid(message: &str) -> io::Error {
    io::Error::new(io::ErrorKind::InvalidData, message)
}

/// IEEE CRC-32, reflected polynomial; deliberately transparent rather than optimized.
pub fn crc32(bytes: &[u8]) -> u32 {
    let mut crc = !0u32;
    for &byte in bytes {
        crc ^= u32::from(byte);
        for _ in 0..8 {
            crc = (crc >> 1) ^ (0xedb8_8320 & (0u32.wrapping_sub(crc & 1)));
        }
    }
    !crc
}

fn encode(key: &[u8], value: Option<&[u8]>) -> io::Result<Vec<u8>> {
    if key.is_empty() || key.len() > MAX_KEY || value.is_some_and(|v| v.len() > MAX_VALUE) {
        return Err(io::Error::new(
            io::ErrorKind::InvalidInput,
            "key/value length outside bounds",
        ));
    }
    let mut record = Vec::with_capacity(HEADER + key.len() + value.map_or(0, <[u8]>::len));
    record.extend_from_slice(MAGIC);
    record.extend_from_slice(&(key.len() as u32).to_le_bytes());
    record.extend_from_slice(&value.map_or(u32::MAX, |v| v.len() as u32).to_le_bytes());
    record.extend_from_slice(&0u32.to_le_bytes());
    record.extend_from_slice(key);
    if let Some(value) = value {
        record.extend_from_slice(value);
    }
    let checksum = crc32(&[&record[..12], &record[16..]].concat());
    record[12..16].copy_from_slice(&checksum.to_le_bytes());
    Ok(record)
}

#[derive(Debug, Default, PartialEq, Eq)]
pub struct Recovery {
    pub entries: BTreeMap<Vec<u8>, Vec<u8>>,
    pub valid_bytes: u64,
    pub records: usize,
    pub torn_tail: bool,
}

/// Replay bounded individual records. The live key map itself grows with the data set.
/// An incomplete declared header/payload returns the validated prefix. Detected magic,
/// length-bound and checksum violations are errors. CRC is checked only after reading
/// the declared payload: a damaged but bounded length can resemble an interrupted append.
pub fn replay(mut input: impl Read) -> io::Result<Recovery> {
    let mut result = Recovery::default();
    loop {
        let mut header = [0u8; HEADER];
        let n = read_prefix(&mut input, &mut header)?;
        if n == 0 {
            return Ok(result);
        }
        if n != HEADER {
            result.torn_tail = true;
            return Ok(result);
        }
        if &header[..4] != MAGIC {
            return Err(invalid("bad record magic"));
        }
        let key_len = u32::from_le_bytes(header[4..8].try_into().unwrap()) as usize;
        let raw_value_len = u32::from_le_bytes(header[8..12].try_into().unwrap());
        let deleted = raw_value_len == u32::MAX;
        let value_len = if deleted { 0 } else { raw_value_len as usize };
        if key_len == 0 || key_len > MAX_KEY || value_len > MAX_VALUE {
            return Err(invalid("invalid record length"));
        }
        let mut payload = vec![0; key_len + value_len];
        if read_prefix(&mut input, &mut payload)? != payload.len() {
            result.torn_tail = true;
            return Ok(result);
        }
        let expected = u32::from_le_bytes(header[12..16].try_into().unwrap());
        if crc32(&[&header[..12], &payload].concat()) != expected {
            return Err(invalid("record checksum mismatch"));
        }
        let key = payload[..key_len].to_vec();
        if deleted {
            result.entries.remove(&key);
        } else {
            result.entries.insert(key, payload[key_len..].to_vec());
        }
        result.valid_bytes += (HEADER + payload.len()) as u64;
        result.records += 1;
    }
}

fn read_prefix(input: &mut impl Read, buf: &mut [u8]) -> io::Result<usize> {
    let mut used = 0;
    while used < buf.len() {
        match input.read(&mut buf[used..]) {
            Ok(0) => break,
            Ok(n) => used += n,
            Err(error) if error.kind() == io::ErrorKind::Interrupted => continue,
            Err(error) => return Err(error),
        }
    }
    Ok(used)
}

fn sibling(path: &Path, suffix: &str) -> PathBuf {
    let mut name = path.as_os_str().to_os_string();
    name.push(suffix);
    PathBuf::from(name)
}

fn sync_parent(path: &Path) -> io::Result<()> {
    #[cfg(unix)]
    {
        let parent = path
            .parent()
            .filter(|p| !p.as_os_str().is_empty())
            .unwrap_or(Path::new("."));
        File::open(parent)?.sync_all()
    }
    #[cfg(not(unix))]
    {
        let _ = path;
        Ok(())
    }
}

pub struct Store {
    path: PathBuf,
    file: File,
    _lock: File, // Separate inode: compaction replaces the data file, never this lock.
    entries: BTreeMap<Vec<u8>, Vec<u8>>,
    poisoned: bool,
    pub recovered_torn_tail: bool,
}

impl Store {
    pub fn open(path: impl AsRef<Path>) -> io::Result<Self> {
        // Freeze the opening cwd before retaining paths used by later compaction.
        // This does not resolve symlinks or protect against external path replacement.
        let path = std::path::absolute(path)?;
        let lock = OpenOptions::new()
            .read(true)
            .write(true)
            .create(true)
            .truncate(false)
            .open(sibling(&path, ".lock"))?;
        lock.try_lock().map_err(io::Error::other)?;
        let file = OpenOptions::new()
            .read(true)
            .append(true)
            .create(true)
            .open(&path)?;
        let recovery = replay(&file)?;
        if recovery.torn_tail {
            file.set_len(recovery.valid_bytes)?;
        }
        file.sync_all()?;
        sync_parent(&path)?;
        Ok(Self {
            path,
            file,
            _lock: lock,
            entries: recovery.entries,
            poisoned: false,
            recovered_torn_tail: recovery.torn_tail,
        })
    }
    pub fn get(&self, key: &[u8]) -> Option<&[u8]> {
        self.entries.get(key).map(Vec::as_slice)
    }
    pub fn len(&self) -> usize {
        self.entries.len()
    }
    pub fn is_empty(&self) -> bool {
        self.entries.is_empty()
    }
    pub fn put(&mut self, key: &[u8], value: &[u8]) -> io::Result<()> {
        self.change(key, Some(value))
    }
    pub fn delete(&mut self, key: &[u8]) -> io::Result<()> {
        self.change(key, None)
    }
    fn ready(&self) -> io::Result<()> {
        if self.poisoned {
            Err(io::Error::other(
                "store write failed; drop and reopen before further mutations",
            ))
        } else {
            Ok(())
        }
    }
    fn change(&mut self, key: &[u8], value: Option<&[u8]>) -> io::Result<()> {
        self.ready()?;
        let record = encode(key, value)?;
        if let Err(error) = self
            .file
            .write_all(&record)
            .and_then(|()| self.file.sync_all())
        {
            self.poisoned = true;
            return Err(error);
        }
        if let Some(value) = value {
            self.entries.insert(key.to_vec(), value.to_vec());
        } else {
            self.entries.remove(key);
        }
        Ok(())
    }
    /// Unix rename + parent sync protocol. Windows replacement semantics are not modeled.
    #[cfg(unix)]
    pub fn compact(&mut self) -> io::Result<()> {
        self.ready()?;
        let temporary = sibling(&self.path, ".compact");
        let mut next = OpenOptions::new()
            .read(true)
            .append(true)
            .create_new(true)
            .open(&temporary)?;
        for (key, value) in &self.entries {
            next.write_all(&encode(key, Some(value))?)?;
        }
        next.sync_all()?;
        fs::rename(&temporary, &self.path)?;
        self.file = next;
        if let Err(error) = sync_parent(&self.path) {
            self.poisoned = true;
            return Err(error);
        }
        Ok(())
    }
}

    }
    #[test]
    fn every_torn_suffix_recovers_only_the_complete_prefix() {
        let first = encode(b"a", Some(b"one")).unwrap();
        let second = encode(b"b", Some(b"two")).unwrap();
        for cut in 1..second.len() {
            let bytes = [&first[..], &second[..cut]].concat();
            let recovered = replay(&bytes[..]).unwrap();
            assert_eq!(recovered.records, 1);
            assert!(recovered.torn_tail);
            assert_eq!(recovered.valid_bytes, first.len() as u64);
        }
    }

        assert_eq!(
            replay(&bytes[..]).unwrap_err().kind(),
            io::ErrorKind::InvalidData
        );
    }
    #[test]
    fn malicious_length_is_rejected_before_allocation() {
        let mut bytes = encode(b"a", Some(b"one")).unwrap();
        bytes[4..8].copy_from_slice(&u32::MAX.to_le_bytes());
        assert!(replay(&bytes[..]).is_err());
    }
    #[test]
    fn overwritten_deleted_and_empty_values_replay() {
        let bytes = [
            encode(b"a", Some(b"one")).unwrap(),
            encode(b"a", Some(b"")).unwrap(),
            encode(b"b", Some(b"two")).unwrap(),
            encode(b"b", None).unwrap(),
        ]
        .concat();
        let recovered = replay(&bytes[..]).unwrap();
        assert_eq!(recovered.entries.get(b"a".as_slice()), Some(&vec![]));
        assert_eq!(recovered.entries.len(), 1);
    }
    #[test]
    fn read_error_is_not_misclassified_as_torn_tail() {
        struct Failed;
        impl Read for Failed {
            fn read(&mut self, _: &mut [u8]) -> io::Result<usize> {
                Err(io::Error::other("injected read failure"))
            }

        assert_eq!(replay(Failed).unwrap_err().kind(), io::ErrorKind::Other);
    }

    }

    #[test]
    fn compaction_preserves_state_and_lock() {
        let dir = Scratch::new();

encode checks caller-supplied lengths, writes fixed-width header fields, inserts a temporary checksum field and appends payload. The checksum covers the first twelve header bytes and the payload, excluding its own field. Including lengths helps detect accidental header damage only when the declared payload can be read completely; the CRC is checked after that read. replay reads the fixed header, checks the magic, interprets deletion, rejects invalid lengths, and only then allocates bounded payload storage. After a complete payload and matching checksum, it updates the map and advances valid_bytes. Those two actions happen together at the end of successful decoding so a partially read record never moves the recovery boundary.

Checksums are evidence with a scope

CRC-32 is an error-detection mechanism for accidental damage. It is not cryptographic authentication, and different byte sequences can share a CRC. The reference has a known-vector test using 123456789, then tests corrupted records. That combination is more informative than simply encoding and decoding with the same code. A checksum mismatch after reading the complete declared payload is a hard error, even at the end of the file. This is narrower than rejecting all corruption of an originally complete record. The parser never scans ahead for another magic string after damage: a magic pattern could occur inside an ordinary key or value, making such recovery ambiguous without a stronger framing protocol.

Acknowledgment order is part of the API

Store::change encodes before writing, calls write_all, calls sync_all, and then changes the in-memory map. The caller receives success only after those steps. write_all handles short successful writes by retrying, but it may still return an error after a prefix was written. A synchronization error can likewise leave an uncertain outcome. The object refuses later writes until reopened. A caller cannot assume that an error means the operation definitely did not occur on disk. This is why higher-level protocols often need operation identifiers and idempotency rules; a local Result alone cannot erase uncertainty introduced by I/O.

Intentional failure and guided checkpoint

Change a copy of the decoder to allocate using the declared key length before checking MAX_KEY. Do not feed it an enormous real allocation. Instead inspect the ordering and write a test that supplies an invalid declared length with no payload. The correct decoder returns InvalidData before requesting that payload. Restore the correct order. Your checkpoint is to describe the validation sequence without reading the implementation: header completeness, magic, bounded lengths, payload completeness, checksum, then map mutation. Engineering decisions and evidence

Current scope and invariants. One cooperating writer owns the separate lock; only a validated record changes the map or recovery boundary. A failed write leaves the last acknowledged map readable and blocks further mutations until reopen.

Why this is the current recommended shape. A small binary protocol and BTreeMap keep framing and replay visible. Bounds precede allocation, typed io::Result values preserve failures, and owned File handles tie cleanup to scope. write_all and sync_all precede acknowledgment; compaction uses a separate lock inode and replaces the active data handle.

Reasonable alternative and tradeoff. An embedded database would provide a broader tested storage contract and should be preferred when a real application needs transactions, indexing, migrations or concurrent readers. This implementation is appropriate for learning one explicit single-writer log protocol; adding a framework would conceal the decisions being studied.

Evidence and limits. Native reference tests were run through mise in the coordinated course verification; inspect the current verification record for exact results. CRC known vector; every truncated suffix of the tested record; checksum mismatch after a complete declared payload; invalid length; read failure; tombstones and empty values; tail repair; lock retention across compaction. Additional self-review regressions cover write-error poisoning and stale temporary files. The live map grows with the data set. CRC is not authentication. A bounded damaged length can resemble a torn tail and cause truncation of an originally complete record; the interrupted-append policy assumes earlier valid bytes were not damaged. Sync/rename tests do not reproduce every power-loss ordering. Unix compaction and cooperating advisory locks are explicit scope limits.

Requirement that would justify evolution. Adopt or evaluate an established storage engine when the requirements include multi-key atomicity, large state, coordinated concurrent readers or portable power-loss guarantees. Do not grow the current log by silently adding assumptions.

A framing counterexample worth keeping

A complete put of key a and value one declares a value length of 3. Change that field to 4 in a disposable copy without changing the file length. The new length is legal, but the decoder now expects a byte that is absent. It reports torn_tail before checking the CRC. Store::open then truncates to the previous validated boundary. Even though the original put was acknowledged, later length damage can cause its removal. The test below deliberately preserves this counterexample so the course cannot quietly overstate the format's guarantee.

mise exec -- cargo test -p p06-kv --test persistence_edges bounded_length_damage

Predict how this differs from flipping one payload bit without changing lengths. Explain when CRC can be evaluated in each case. For unknown real damage, preserve the original bytes before opening a copy for inspection. A future format with independently checked framing needs its own version and migration tests; CRC would still not provide authentication or eliminate collisions.
